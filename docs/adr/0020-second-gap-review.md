# ADR-0020 第二轮对照：戴森球计划和无人深空剩下的缺口

- 状态：已采纳
- 日期：2026-10-20

## 背景

- M9 做完以后，ADR-0013 列的缺口都补上了。2026-10-20 用户要求"继续对照与戴森球游戏和无人深空游戏的差距，完全做出来，融合两游戏的优点，完成度极高"，同一天又提出"场景要宏伟，太空的视觉效果因为行星太小距离太近而没有巨物感觉，我希望你对照 NASA 的照片进行制作"。
- ADR-0013 当时标成"不做（P2）"的几项（黑雾、外星文明、货船舰队、潜艇和机甲），这次也在范围里。
- 本 ADR 逐个系统对照两款游戏和现在的代码（2026-10-20 的提交 d7b9c43），列出缺口，排出 M10 以后的里程碑。"完成"的标准沿用 ADR-0013。

## 决定

### 太空的尺度和画面

| 项目 | 现状 | 要做 |
|---|---|---|
| 尺度 | 母星大小的星球在太空里半径 110 格，相邻行星隔一两千格，脉冲引擎几秒飞到 | 星球和轨道放大一个数量级，相邻行星之间开脉冲引擎半分钟到一分钟 |
| 飞行范围 | 飞船只能在黄道面上下几百格里飞 | 绕着星球上下左右都能飞，飞到南北极上空 |
| 星球的画法 | 天球上的圆盘，正交投影，近处画不出地平线 | 逐像素光线求交的球体，近地轨道看是一道弯曲的地平线 |
| 大气 | 边缘一圈辉光 | 单次散射：地平线上一道蓝线，晨昏线发红，越靠边越朦胧 |
| 表面 | 五种程序纹理 | 按 NASA 照片做：类地（蓝色弹珠）、月面、木卫二、木卫一、火星、土卫六、海王星、木星、土星和它的环 |
| 恒星 | 圆盘和光晕 | 眩光、镜头光斑，被星球挡住时日食 |
| 速度感 | 只有跃迁有特效 | 脉冲飞行时的太空尘埃，进出大气的火焰和过渡 |
| 星球上看天空 | 视大小压缩过的圆盘 | 同一套着色器；有环的星球能登陆，天上横着一道环 |

### 里程碑

| 里程碑 | 内容 | 退出标准 |
|---|---|---|
| M10 宏伟的太空 | 上面"太空的尺度和画面"一节 | 截图和 NASA 照片放在一起看，近地轨道、远看星球、土星类的环、恒星眩光都对得上；从起飞到降落另一颗行星，中间的脉冲飞行在半分钟以上 |
| M11 工厂深度 | 增产剂、传送带堆叠和相关工具、电力补全、四种高级设备、叠放、星图资源和探索科技、缺的物品 | 一条用了增产剂和堆叠传送带的产线，产量比不用时高 |
| M12 机甲 | 能量核心、持续飞行、建造无人机、物流配送器和机器人、外骨骼升级科技 | 拿着蓝图走过去，无人机自己把一片工厂建好；物流栏位自动补货 |
| M13 飞船与航行 | 飞船成长、货船和护卫舰、跃迁档次、太空遭遇 | 买到一艘现成的船并装上技术模块；派护卫舰出一次远征；用黑洞跳到星团另一头 |
| M14 星球生活 | 植物资源和种植、烹饪、精炼机、水下、兴趣点、守卫机、武器、载具、动物、世界边界、庇护所 | 在一颗新星球上靠就地采集活下去，种出资源植物，开潜艇看水下兴趣点，打退五级通缉 |
| M15 外星文明 | 种族、NPC、语言、声望、对话、公会 | 在空间站和据点里和 NPC 对话、学会单词、声望升一级 |
| M16 黑雾 | 黑雾全部，建世界选项 | 守住一次黑雾进攻，打掉一个地面基地 |
| M17 音效和打磨 | 原创音效，各系统的收尾 | 主要设备、飞船、武器都有自己的声音 |

M10 先做：用户这一轮专门提了太空画面，而且尺度一改，物流、小行星带、空间站、跃迁的数字都要跟着改，越早改，后面的里程碑越少返工。

## 理由

- 两款游戏的乐趣在 ADR-0013 补完后还差几块大的：戴森球计划的增产剂和堆叠决定后期产线的形状，机甲的建造无人机让玩家从"摆方块"变成"规划工厂"；无人深空的飞船成长、外星文明、货船是中后期一直往前推的目标。
- 黑雾放在最后：它和守卫机、海盗的战斗系统可以共用一部分代码，等那两套做深了再做，返工少。
- 外星文明的设定、台词属于剧情，按用户的要求（2026-10-19）另外讨论；系统先做，文字放占位。

## 后果

- 路线图加上 M10–M17。每一项按 ADR-0013 的"完成"标准做完才打勾。
- 太空尺度改了以后，旧存档里放在太空的方块（轨道采集器）离新位置的气态巨行星很远，要重新放。Alpha 还没公开发布，在更新日志里写明。
- 立项书 §4.2 的非目标里，"NPC 文明""货船舰队"改为在范围内，指向本 ADR。

## 备选方案

- 只把星球画大，不改太空的尺度：飞得太快，从一颗行星到另一颗还是几秒，画面再大也没有距离感。
- 太空用浮动原点（ADR-0008 的方案 B）、飞船坐标和物理坐标分开：多人同在一个太空维度时，每个人的原点不同，海盗、小行星、空间站都要换算，工作量大，收益只是能飞得更快。真实坐标在 40–60 格/刻时每刻 5 ms 左右，够用。
