# ADR-0030 各系统的收尾：酸液、奇异星球、模组互通、戴森球编辑和零散的尾巴

- 状态：已采纳（M17）
- 日期：2026-10-22

## 背景

- 路线图 M17 的第二项"各系统的收尾"。M5 到 M16 每个里程碑都留了"留到以后"，有的地方代码已经做了、文档还写着没做。2026-10-22 把代码、路线图、ADR 和玩法设计对了一遍，没收尾的有三十来项。
- 大的几块：
  - 酸液：玩法设计 §2.1 把酸液列为三种液体之一，§9.1 有酸液泵；ADR-0005 写着"酸液暂时用水"，到现在还是水。毒雾星球的酸海能喝、能种水生植物、能抽水，抽水站界面写"无法抽取酸液"，一直没有别的出路。
  - 奇异星球的子类型：ADR-0020 给 M14 列了，M14 只做了世界边界。现在的奇异星球只是配色怪一些。
  - 和其他模组互通：立项书 §4.1、玩法设计 §9.4 和 §11 写了 NeoForge 的能量、流体接口。现在只有物品接口（`FactoryCapabilities`）。
  - 戴森球编辑：ADR-0020 列了"自由摆放、上色、蓝图"，没排进任何里程碑。现在一层只能选测地网、六边形、经纬网三种模板（`DysonGrid.Template`）。
- 小的：太空里太阳能板平放；星际运输船在太空维度里看不见；蓝图记不住分流器、流速监测器、研究站的增产模式和战场分析基地的过滤；四种高级设备没有黑雾掉落的便宜配方（ADR-0022 说过以后加）；开着飞船打不开货舱；别人的喷气背包火焰看不见；放下的星球植物总是第一个物种；掉落物、箭不按星球重力落；黑雾巢穴里还有实体没做好时的保护代码。
- 声音（M17 第一项）见 ADR-0029，本 ADR 不管。

## 决定

### 一、酸液

- 酸液是单独的流体，有源头和流动两种状态，能用桶装。毒雾星球、液体是酸液的奇异星球的海，和洞里的含水层，都是酸液。照现实里的浓硫酸：比水重、稍稠，流得慢一点；颜色跟星球的液体色，偏黄绿。
- 泡在酸液里：毒性防护掉得快，没有防护直接受伤，掉进去的物品慢慢被腐蚀掉。酸海里不生成水生生物和水生植物。潜艇照样能在酸液里开。
- 抽水站放在酸液源头上抽出硫酸，和戴森球计划的硫酸海一样，是化工线之外硫酸的另一条来源。
- 酸雨：雨滴染成黄绿色，淋着时毒性防护掉得快，和毒雾一起算。

### 二、奇异星球的子类型

- 新派生键 `exotic`，每颗奇异星球一种子类型，照现实里的极端地貌放大到整颗星球：
  - 柱状玄武岩：巨人堤道、魔鬼塔那样的六棱石柱，高低错落。
  - 石林：布莱斯峡谷那样细高的岩柱，顶上压着一块硬岩。
  - 巨晶：墨西哥奈卡洞那样几十格长的晶柱，斜插出地面。
  - 结核球：新西兰摩拉基大圆石、火星"蓝莓"那样的圆石，散在地上、半埋在崖壁里。
  - 多边形地面：火星和盐湖上的多边形裂纹，平地上一圈圈矮脊。
  - 天然石拱：美国拱门国家公园那样的石拱和石桥。
- 星图、发现日志和分析目镜写出子类型。

### 三、和其他模组互通

- 电网接口：新设备，在电力感应塔范围里接进电网。界面里选输入或输出：输入时把别的模组送来的能量当发电机并进电网，输出时从电网取电往外送。对外提供 NeoForge 的能量接口，1 J = 1 FE（ADR-0011），每刻最多 2250 J，和能量枢纽一样。
- 储液罐、抽水站、原油萃取站对外提供 NeoForge 的流体接口。流体物品和流体按一个对一桶（1000 mB）换算。水对应原版的水，酸液对应模组自己的酸液，原油、精炼油、氢、重氢按 NeoForge 的通用流体标签找别的模组的流体；找不到对应流体的物品不从流体接口进出，照旧走物品接口。

### 四、戴森球的自由编辑、上色和蓝图

- 一层可以不用模板：节点按经纬度吸附着摆，两个节点之间连框架，框架围成的圈铺壳面。模板生成的层也能接着改：删节点、加框架、补壳面。改动按戴森球计划的规矩，已经建了结构的节点、框架不能直接删，要先拆（拆下的结构点不退）。
- 节点、框架、壳面能上色：一排预设颜色加自定义 RGB。天上、太空里、编辑器里都按这个颜色画。
- 戴森球蓝图：一层的结构和颜色导出成一串文字，复制到剪贴板，也存进本地的蓝图库；导入到还没开始建的层。文字里带版本号，坏的、别的版本的串给出原因。
- 太空里背面的球壳也画出来（M6 留下的）。
- 读旧存档时没有自定义网格的层照旧按模板读。

### 五、工厂和物流的尾巴

- 太空里的太阳能板转向恒星。
- 星际运输船在恒星系的太空维度里看得见：从起点星球的大气球飞到终点的，跨恒星系的在恒星系边上跃迁离开。
- 蓝图记住分流器的优先级和过滤、流速监测器的设置、研究站的增产模式、战场分析基地的拾取过滤。
- 负熵熔炉、重组式制造台、量子化工厂、自演化研究站各加一条用黑雾掉落的配方，比现在的便宜。
- 补游戏内测试：漏斗从物流站往外抽、比较器读物流站、装了引力透镜的射线接收站在看不见恒星时照样接收。

### 六、飞船、外骨骼和星球的尾巴

- 开着飞船也能打开货舱：船上所有箱子、木桶拼成一个界面，按键打开。
- 喷气背包的火焰同步给附近的玩家。
- 放下的星球植物按所在星球的物种显示。
- 掉落物、箭、雪球这类不是生物的实体也按星球重力下落：低重力的星球上箭飞得远，掉落物飘得久。
- 黑雾巢穴里"实体还没做好"的保护代码删掉。

### 七、文档

- 代码做了、文档还写着没做的一并改掉：世界边界、太空的重力、星球矿石、Iris 兼容的测试、戴森球的画质开关、多人测试、水生生物、繁殖、潜艇的前置、守卫机型多功能工具、水产菜、核心残骸的地热等。
- 玩法设计 §9.5、§12 改成下面"不做"里定的样子。
- 发布页按 M10–M17 的内容重写，换新截图。

### 不做的

- 行星在太空维度里沿轨道移动。
- 研究按队伍分开，物流站、发电设备归队伍。
- 原版的雕刻器（峡谷、洞穴雕刻）。
- 跨恒星系的中转站（无人深空的空间异常）。
- 黑雾和守卫机互相打（ADR-0028 已定）。
- 背景星空的引力透镜变形（ADR-0024 已定）。
- 飞船上的方块在飞行时工作。
- 小行星打碎后的冷却存档。

## 理由

- 酸液：毒雾星球现在和宜居星球一样有一片能喝的海，"有毒"只剩空气。单独做流体以后，海本身就是危害，抽水站也多了一种产物。戴森球计划的硫酸海就是早期硫酸的来源，接上以后不想建原油线的人有一条路。
- 奇异星球的子类型照现实里的地貌：巨人堤道、石林、奈卡洞、摩拉基大圆石、火星的多边形地面、拱门国家公园都真实存在，只是放大到一整颗星球。无人深空的奇异星球（柱状、气泡、六边形、碎片）有同样的感觉，但我们不照搬它的形状。
- 电网接口单独做一个设备：本模组的电网不拉线，按电力感应塔的范围结算，每刻一结（`LevelPower`）。别的模组的电缆随时充放，和满足率的算法对不上；接口每刻按电网的结算收发，边界清楚。
- 流体按一个物品对一桶换算：玩家脑子里的"一桶水"就是一个水，别的模组的管道按桶计量也直观。
- 戴森球计划的戴森球玩法一半在设计球的样子，玩家互相分享球的蓝图。只有三个模板时，所有人的戴森球长一个样。蓝图用文字：戴森球计划也是这样，能贴到聊天里、网上分享，不用先在游戏里建一层。
- 不做的：
  - 行星移动：空间站、轨道采集器、小行星带、黑洞、黑雾巢穴、遭遇都按固定坐标放在太空维度里，行星一动它们都要跟着动；脉冲飞行要半分钟以上，目标还在跑，自动驾驶和物流船都要追着算。无人深空的行星也不动。星球上看到的天空照样按轨道转（`SkyModel`）。
  - 研究和设备归队伍：科技的效果按世界读（`Research.level(level, …)` 有四十多处），改成按队伍要把玩家一路传进去；联机时大家一起推科技树，戴森球计划的联机模组也是这样。物流站本来就全服共用一张网。
  - 雕刻器：星球的洞穴由噪声生成（芝士洞、面条洞），峡谷有"大峡谷""裂谷"两种地貌；26.3 的雕刻器接口变了，接进来的收益小。
  - 中转站：无人深空的空间异常是剧情角色和联机大厅；它的功能（科技商人、任务、去别的恒星系）空间站的科技商、公会使者、任务板和传送网络都有了。角色和剧情要和作者另外讨论。
  - 船上的方块工作：飞船的方块飞行时存在实体里，让它们运转要再模拟一套方块实体；无人深空的飞船里也没有工作的设备，要建基地有货船。
  - 小行星冷却：重启服务器以后，刚打碎的小行星提前回来，没有影响。

## 后果

- 新的派生键 `exotic`，已有的宇宙里别的东西不变。
- 已经生成的区块里，毒雾星球的海还是水，新生成的区块是酸液，交界处会看到一道边。Alpha 没有公开的存档，在更新日志里写明。
- 新的存档字段：戴森球层的自定义网格和颜色。没有这些字段的旧存档照旧读。
- 网络协议版本加一。
- 新设备电网接口、新物品酸液桶，都要在生存里拿得到，由 `SurvivalProgressionTest` 检查。

## 备选方案

- 酸液继续用水、只换颜色：现在就是这样，酸海能喝、能抽水、水生生物照样游。不用。
- 能量接口直接加在蓄电器上：外面随时充放，蓄电器的电量和电网每刻的结算对不上。不用。
- 戴森球蓝图做成物品：要先在游戏里建出一层才能复制，也没法在网上分享。不用。
- 行星按轨道移动、太空里的东西都挂在行星上：上面说的那些系统都要改，开销最大的一项，收益只是看着更真。不用。
