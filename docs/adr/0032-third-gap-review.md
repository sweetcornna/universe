# ADR-0032 第三轮对照：两款原作 2024 年以来加的东西

- 状态：已采纳
- 日期：2026-10-23

## 背景

- ADR-0020 列的缺口在 M10–M17 补完了。2026-10-23 用户再次要求："完成度要极高，要复刻戴森球和无人深空玩法"。
- ADR-0020 对照的是两款游戏 2024 年初的样子。这两年它们一直在更新：
  - 戴森球计划到 0.10.35（2026-09-23），还在抢先体验，没有 1.0。2026 年 1 月的开发日志说载具编辑器、空间站和太空战是正式版之前最后一个大更新，没给日期。
  - 无人深空从 4.60 Orbital（2024-03）到 7.00 Cosmos（2026-09），中间有钓鱼、世界重做、化石、聚落、可拼装的护卫舰、生物对战、深空兴趣点。
- 资料：戴森球计划的 Steam 公告（逐条读了 2024-01 以来的更新说明）；无人深空官网每次更新的说明页，日期按 Miraheze 维基的版本表和媒体报道核对。
- 这次还把两款游戏的核心系统重新过了一遍，补上前两轮漏掉的。"完成"的标准照旧（ADR-0013）。

## 决定

### 戴森球计划

| 系统 | 原作 | 现状 | 要做 |
|---|---|---|---|
| 机甲的舰队 | 0.10.29 起：地面编队（原型机、精准无人机、攻击无人机）跟着机甲打地面的黑雾；太空舰队（护卫舰、驱逐舰）打巢穴。机甲面板里配编队，按键出动，耗机甲能量，打掉了从背包自动补 | 炮塔、信号塔；无人深空式的货船护卫舰远征清剿巢穴 | 地面编队和太空舰队，三种无人机和两种战舰（名字避开已有的"护卫舰"），编队界面、出动和召回、补员 |
| 机甲的战斗 | 能量护盾挡伤害、按住放护盾爆发、自动和手动开火、投掷干扰胶囊和水 | 投掷燃烧单元、爆破单元 | 能量护盾、护盾爆发、开火模式、投掷干扰胶囊 |
| 星际物流的调度 | 0.10.30：五级优先（点对点配对、星球物品路线、星系物品路线、站点分组、普通配对），路线能指向没有工厂的星球，隔离配对，配对的路线画在星图上 | 按供需自动配对 | 全部 |
| 控制面板 | 全星团的星际站、行星站、配送器列在一张表上，能排序、筛选、跳过去改设置 | 要走到站前面右键 | 全部 |
| 统计 | 物品搜索、上下游、参考产量、按星球和星系的进出口、电力饼图、戴森球每层的统计；仪表盘把自选的实时图表钉在屏幕上 | 生产统计面板：产量和耗量 | 上下游、进出口、电力和戴森球的分项、仪表盘 |
| 研究队列 | 排几项研究、调顺序 | 一次只能研究一项 | 队列 |
| 全息信标和备忘 | 0.10.34：信标方块当地图标记，带备忘；备忘能贴在星球、星图、蓝图上，有图标、颜色、勾选框 | 无 | 全部 |
| 黑雾透镜 | 0.10.35：射线接收站用黑雾材料做的透镜，损耗更低、收得更快 | 只有引力透镜 | 黑雾透镜（配方用黑雾掉落） |
| 矿脉 | 矿脉快采完时提醒，在星球上高亮某一种矿 | 平视显示器标出附近矿脉 | 枯竭提醒、按矿种高亮 |
| 蓝图 | 连地基一起复制、只贴设备、作者和版本、粘贴时显示地基和土的花费 | 蓝图能存、能贴、带设置 | 只贴设备、作者和版本、显示花费 |

不做：
- 植被移植、地形复原：Minecraft 本来就能挖、能种、能填。
- 电力塔按网格拖放、沿经纬线铺地基：Minecraft 是一格一格放的，没有球面网格。
- 多线程、截图模式：引擎不一样。
- 预告的载具编辑器、空间站、太空战：还没发布；方块拼装的飞船（ADR-0008）、空间站、飞船战斗已经有了。等原作发布了再对照。

### 无人深空

| 系统 | 原作 | 现状 | 要做 |
|---|---|---|---|
| 钓鱼 | 5.10 Aquarius：多功能工具装钓鱼器；什么食物都能当饵，也能做专门的饵；160 多种鱼，按星球、生物群系、昼夜、天气、水深出；图鉴记最重的一条；能放生；会钓到垃圾和科技；自动捕鱼笼；海鲜菜谱 | 水生生物打了掉鱼肉 | 全部（掠水艇不做，已经有潜艇和悬浮车） |
| 聚落 | Frontiers 起、5.70 Beacon 加深：玩家当总督，认领聚落，盖建筑、升级建筑，居民来请愿、要你做选择，人口、幸福、产出，海盗来袭要守，最多管四个 | 三个种族的聚落，只能对话、交易、学词 | 认领、建设项目、请愿和决定、人口和产出、海盗袭击和守卫、建筑升级 |
| 化石 | 5.60 Relics：化石床挖出几百种骨头部件，展台上拼完整的骨架，打包卖给收藏家 | 化石坑和化石土出三种化石 | 骨头部件、展台和骨架、收藏家 NPC |
| 深空 | 7.00 Cosmos：小行星带、冰带、碎片带、废弃前哨站；拆解巨型残骸（拆错了会熔毁）；牵引光束；抛货；任何船都能出舱，六自由度的喷气背包 | 小行星带、废弃货船、空间站、站外的太空行走 | 碎片带、废弃的太空前哨站、拆解残骸、牵引光束、抛货、任何船停在太空里都能出舱再飞回来 |
| 科技的相邻和超频 | 同类模块挨着放有加成，超频格把效果放大（核心系统，前两轮漏了） | 技术模块各算各的 | 相邻加成、超频格 |
| 局部危害 | 5.50 Worlds Part II：孢子云、放射性尘埃、火山喷发、间歇泉 | 风暴 | 间歇泉、火山喷发、孢子云、沙尘里的尘卷风 |
| 重力枪 | 6.20 Remnant：多功能工具的附件，抓起东西扔出去，守卫机也能抓 | 无 | 重力枪附件 |

1.0 之后再看：
- 生物对战（6.30 Xeno Arena）：回合制的小游戏，系统大，和两款游戏的主线关系远。
- 活体飞船：要另做一套长出来的飞船，和方块拼装的思路冲突，以后单独讨论。
- 太空异常（多人的中心枢纽）、空间站总督、星系联盟：多人服务器上的社交系统，等多人玩的人多了再看。

不做：
- 登陆气态巨行星、紫色恒星、泰坦星球、浮空岛：现实里没有。气态巨行星没有地面，紫色的恒星不存在（立项书 §5、ADR-0025）。
- 飞行中在护卫舰里走动：飞船飞的时候是一个实体，里面走动要另写一套物理，停着的时候本来就能走进去。
- 远征：要运营方开赛季。

### 里程碑

| 里程碑 | 内容 | 退出标准 |
|---|---|---|
| M18 机甲舰队和物流调度 | 上面戴森球计划一节 | 带一支地面编队和一支太空舰队各打掉一个黑雾目标；一条点对点配对的星际物流线和一条运到没有工厂的星球的路线都跑起来；在控制面板里改一个远处物流站的设置；仪表盘上钉一张产量图 |
| M19 钓鱼、聚落和深空 | 上面无人深空一节 | 在三颗不同的星球钓到不同的鱼并记进图鉴；认领一个聚落，盖完一个建设项目，守住一次海盗袭击；在展台上拼出一副完整的骨架；拆解一艘残骸 |

- 1.0 放在 M19 之后。化学与生物研究（ADR-0025）改为 M20，目标还是 1.1。
- M17 的材质重画照常先做完。

## 理由

- 舰队是戴森球计划战斗更新的另一半：现在只有固定的炮塔，玩家打黑雾基地只能靠自己和炮塔推过去；有了舰队才是"带着部队去清剿"。
- 物流调度和控制面板决定星际工厂规模变大以后还管得过来，是原作 2024 年两次大更新的重点。
- 钓鱼、聚落、化石是无人深空这两年最受欢迎的几块，和 Minecraft 原有的钓鱼、村庄、考古的玩法接得上。
- 相邻和超频是无人深空配科技的核心乐趣，前两轮只对照了"有没有模块"，没对照摆法。
- 不做的几项按"以现实为底"（ADR-0025）筛掉；推迟的几项是系统大、和主线关系远。

## 后果

- 路线图加上 M18、M19，原来的 M18 改为 M20。时间表里 1.0 移到 M19 之后。
- 舰队的战舰不能叫"护卫舰"，货船的护卫舰（ADR-0024）已经占了这个名字。
- 原作还在更新。正式版发布时（戴森球计划的 1.0、无人深空下一个大版本）再对照一轮。

## 备选方案

- 只补戴森球计划这边、把无人深空的新内容放到 1.0 之后：用户要的是两款都复刻完整，无人深空这两年加的钓鱼、聚落是它现在的核心玩法之一。
- 把这些塞进 M17：M17 是音效和打磨，材质重画已经很大；分成两个里程碑，各自有能验收的退出标准。
