# ADR-0039 第四轮对照：系统之间的联动和没收完的尾巴

- 状态：已采纳
- 日期：2026-10-31

## 背景

- 前三轮（ADR-0013、0020、0032）对照的是"两款原作有、我们没有"的系统。到 M21，单个系统基本都有了，每个都单独验过。
- 2026-10-31 用户问"还有什么地方做得不完全，可玩性和联动性有待提升"。这一轮反过来查：各系统做出来的东西流到哪里去，系统之间有没有互相影响。查法是三个只读的代理分别读化学和生物、敌对系统、探索和社交三块的代码，结论逐条抽查核实过。
- 主要发现：
  - 通关只要沿戴森球计划那条矩阵链研究到"任务完成"（`TechTree.java:211`）。勘探数据只挡住跃迁研究，可跃迁本身只看背包里有没有空间翘曲器（`ShipWarp.java:111`），空间站又直接卖翘曲器和跃迁引擎；主线要的资源母星系里全有，特殊恒星的资源都有替代配方。
  - 信用点的大头花费都是一次性的（货船、飞船、多功能工具），没有跟着工厂规模涨的去处。
  - 聚落终端没有物品接口，产出只能手拿；建设要的材料量小，而且只要一次。
  - 敌对系统各打各的：黑雾不理守卫机、海盗和聚落；机甲舰队和炮塔只打黑雾；机甲的武器打不到海盗（`PirateFighter` 不是生物实体）；物流运输船只是一本账，没人能截；海盗和守卫机的强度不随进度涨。
  - 星球改造只改了生存这一层（危害、天气、天空、氧气）。动植物、钓鱼、微生物、守卫机、普通资源植物都按原来的星球算（`Terraform.java:219-221`），星图和发现日志上的温度、危害也是原样；改造到能呼吸只换来一个进度。
  - 没有去处的东西：光学晶体没有配方用；海盗残骸只能卖；氩、氦只能卖或者放进释放塔；镍、铂没有价钱，卖不掉；样品、菌种管、改造种苗带着数据组件，卖不掉；舰队终端不认甲烷液氧燃料；藻类生物质除了固氮和烧掉没有用。
  - ADR-0036 答应了没做的：荧光素酶没有效果；种下的改造种苗丢掉基因；藻类做不了生物胶质和食物；空间站不卖镍；发现日志看不到改造的阈值。
  - 互通：配方写死 `minecraft:iron_ingot` 这类原版物品，不认 `#c:ingots/iron`；本模组的矿、粗矿、锭没登记 `c:` 标签。玩法设计 §11 的"下界石英是前期的硅来源"没做。
  - 钓鱼、聚落、化石、深空、公会没有进度；M19 给它们留的升级科技位置是空的（`TechTree.java:387-391`）。
  - 新手引导只有探测器日志 6 页、手册和进度，剧情节点 5 个，没有目标追踪；外星人的对话题目只有 6 个，任务只有 6 种、一次只能接一个。
  - 黑雾的地面进攻要那颗星球上有人才发生（`DarkFogBases.java:595-597`），用工厂锚挂着的外星基地永远不会被打。
  - 每一段都验过，但没有人从零开始完整玩过一遍；M20 的退出标准没有整条走过，化学手册和反应釜列表没在客户端里看过；更新日志没有 1.1。

## 决定

分两个里程碑做，剧情和命名最后和作者讨论。

### M22 收尾和打通（1.1）

小而快的一批，不改玩法的结构。

| 项 | 做法 |
|---|---|
| 光学晶体 | 光子合并器的替代配方：1 光学晶体 + 1 电路板 → 1 光子合并器（戴森球计划的光栅石配方）。现实里冰洲石就是做偏光棱镜的料 |
| 海盗残骸 | 新标签 `universe:combat_salvage`：守卫机残骸和海盗残骸。技术模块的配方改用这个标签，打海盗也能凑模块 |
| 氩 | 钛合金的替代配方：4 钛锭 + 4 钢材 + 1 氩 → 4 钛合金，代替 8 份硫酸。现实里钛在氩气保护下熔炼、焊接 |
| 氦 | 超级磁场环的替代配方：液氦冷却的超导磁体，同样的料出 2 个 |
| 氩和氦从哪来 | 两种气体主要在奇异星球的大气里（六成带 1–20% 的氦、2–15% 的氩，`AtmosphereMixes.exotic`），这两条配方顺带给了去奇异星球的理由 |
| 镍、铂 | 定价钱；空间站的常备货里加镍锭（ADR-0036 §四） |
| 样品、菌种管、改造种苗 | 带着的数据组件不再挡着卖 |
| 舰队终端 | 甲烷液氧燃料按 2.5 份发射燃料算 |
| 藻类生物质 | 生物胶质的配方；营养处理器做藻饼（螺旋藻那样的食物） |
| 改造种苗 | 种在地里的留住基因，拆下来掉回同样的种苗；带荧光素酶的发光（现实里 2020 年做出过带真菌荧光素酶的发光烟草） |
| 改造后的环境 | 星图、发现日志、分析目镜按改造后的样子写温度、大气、危害；发现日志加改造进度和四道阈值 |
| 通用标签 | 本模组的矿、粗矿、锭、宝石登记 `c:` 标签；配方里的原版铁、铜、金锭等改用 `c:` 标签 |
| 下界石英 | 电弧熔炉：石英炼硅（现实里硅就是石英和碳在电弧炉里还原出来的） |
| 进度 | 钓鱼、聚落、化石、深空、公会各加几个 |
| M20 收尾 | 退出标准写成一个游戏内测试整条走一遍；无头客户端看化学手册和反应釜列表；更新日志加 1.1 |

不改的：

- 氰化氢、催化剂和别的化学中间体留在化学这一块里。反应釜本来就是做反应的沙盒（ADR-0037），这些东西能卖就够了，不硬塞去处。
- 新加的替代配方会被平衡模型拿去算最便宜的路线。氩、氦按大气提取器在奇异星球上的产量折成矿，记进 `Progression.EXTRACTED`，和黑雾掉落一样定得比开采贵，免得替代配方让按开采算的进度变快。

退出标准：上面列的东西每样都有了卖以外的去处；M20 的退出标准由游戏内测试整条走过；单元测试、GameTest、数据生成检查全过。

### M23 联动（1.2）

改玩法结构的一批，每一项开工前再写细。

1. **稀有资源进主线**：黄矩阵往上，每档至少有一种原料走"稀有资源"的捷径（戴森球计划的光栅石、分形硅石、单极磁石那样），只在特定的星球或恒星类型上有。要不要做成硬门槛（不去就做不出来）由作者定，见下面"待定"。
2. **大宗合同**：空间站按批次收矩阵、处理器这类工厂产品，付信用点和声望，量跟着空间站的经济类型和玩家的规模走；信用点能买研究数据，缩短一项研究。
3. **聚落接物流**：聚落终端当一个物流的供需点，聚落的长期需求（食物、建材、电路板）跟着人口涨，产出也能进物流。
4. **敌对系统互相影响**：黑雾和守卫机互打（ADR-0028 留的"以后再说"）；炮塔和机甲舰队对所有敌人都有效；海盗按星际物流线的运量劫道，被劫的运输船丢货；海盗的强度跟着玩家货船的档次走。
5. **改造影响生态**：宜居化以后换上宜居的植被和动物，守卫机变少，钓鱼和微生物跟着变；改造到能呼吸记成一个剧情节点。
6. **远处的基地也要守**：没人的星球上黑雾照样进攻，照聚落的办法按防御值结算（炮塔、护盾、设施的耐久），结果写进通知。
7. **UNV-7 的引导任务线**：从修好多功能工具到第一次跃迁，一步一个目标，HUD 上能看到；之后按玩家走到哪一步把钓鱼、聚落、化学这些系统依次带出来。文字先放占位，和剧情一起定稿。
8. **任务和对话**：任务加几种（护送、改造、捕获），能同时接三个；对话题目扩到每个种族十几个（文字和剧情一起定稿）。
9. **M19 的升级科技**：钓鱼、聚落、化石、深空各一条。

退出标准：每一项开工时定。

### 从零开始的生存通关

M22 做完以后做一次：新世界、生存模式、不用命令，用开发脚本加速时间跑通主线，记下每段的实际时长，和 `BalanceTest` 的模型对照。查出来的节奏问题放进 M23。

### 待定（和作者讨论）

- 剧情：日志、先驱者的回应、结局、外星种族的设定和台词、黑雾的来历（最后讨论）。
- 命名：Emeril Drive、Sentinel、Space Warper、Universe Matrix、Dark Fog、卡西米尔晶体这些直接来自两款原作的名字，立项书 §6 说是工作名，要换成原创的。
- 探索要不要成为主线的硬门槛：做了以后"只在母星系也能通关"就不成立了。2026-10-31 用户定了软门槛：黄矩阵往上每档加稀有资源的捷径配方，出去探索明显更快，不去也能通关，老存档的产线不受影响。

## 理由

- 系统已经够多了，再加新系统不如让现有的互相用上。玩家觉得"什么都有、什么都可以不碰"，问题在去处，不在数量。
- M22 先做是因为都小、互不牵扯，能单独测，做完就能发 1.1；M23 每一项都要改两三个系统的接口，要先定细节。
- 替代配方而不是改主配方：老存档里的产线不受影响，戴森球计划本来也是这么做稀有资源的。
- 通关测试放在 M22 和 M23 之间：M23 要调的节奏，得先量出来。

## 后果

- 新的标签 `universe:combat_salvage`、新配方、新进度，都是新加的，存档不受影响。
- 资源植物的方块加两个状态（改造过、发光）和一个只在改造过时才有的方块实体。已有的植物读进来按默认值（没改造、不发光），存档不受影响。
- 配方的原料从具体物品改成 `c:` 标签：别的模组的同种锭也能用，本模组的锭也能进别的模组的配方。JEI 里原料格会轮着显示同标签的物品。
- 平衡模型多两种按产量折算的原料。

## 备选方案

- 删掉没有去处的东西：存档里已经有了，删注册名会丢物品（ADR-0035 的存档承诺）。不用。
- 把氩、氦、光学晶体做成主配方的必需品：一下子改变现有产线，老存档的玩家要拆了重建。放到 M23 和"稀有资源进主线"一起考虑。
- 一次做完 M22 和 M23：M23 改动大，和 M22 混在一起不好测，也拖慢 1.1。

## 结果

### M22（2026-10-31）

- 没有去处的东西都接上了，配方和价钱照"决定"一节的表。做的时候改了两处：
  - 超级磁场环的超导配方是三台涡轮、三块磁铁、一块高能石墨加两份氦出两个环，比"同样的料出 2 个"保守，工时也翻倍。
  - 藻类做的菜不另加物品，按海带脆片算（营养处理器 3 份藻出 1 份）；另加一条藻熬琼脂（现实里琼脂就是红藻提的）。
- 平衡模型：替代配方按最便宜的路线算。氩、氦早就按提取器的产量记在 `Progression.EXTRACTED` 里，光学晶体按开采的四倍记进去；各档研究时长和改之前一样（蓝红 0.94 小时、蓝红黄 2.68 小时）。
- 通用标签：
  - `UniverseItemTags.COMMON` 一张表管本模组材料和标签的对应，按物品 ID 排序（`Map.ofEntries` 的顺序每次启动都不一样，数据生成会写出不同的文件，CI 的数据生成检查第一次就因为这个红了）。
  - 设备配方写进注册表前由 `CommonTagRecipes`（包一层配方的引导上下文）把单一物品的原料换成标签，数据生成里不用一处处改。
  - 读配方的单元测试（平衡、价钱、生存可达、原子守恒）用 `GeneratedTags` 展开本模组写出的标签；原版和别人的标签本模组只往里加了几样，不展开。
  - 原版的铁、铜、金不换：别的模组本来就用原版的物品，换成标签只多出 JEI 里轮播的图。
- 种下的改造种苗：基因记在区块的附加数据上（`engineered_plants`），不加方块实体，免得世界生成的几十万株野生植物都多一个空的方块实体。方块加一个 `glowing` 状态管荧光素酶的亮度。拆、炸、活塞顶掉都在 `affectNeighborsAfterRemoval` 里掉回种苗；创造模式拆也会掉，没区分。
- 星图、发现日志、分析目镜改读 `ClientGalaxy.environment(planet)`；发现日志对改造过的星球列四档和六道门槛（`ThresholdRows`），在星球上打开时直接选中脚下这颗。
- 进度 7 个，用现有的 `universe:milestone` 触发器在各自发生的地方报。
- M20 的退出标准由 `M20ExitGameTests` 三个游戏内测试走完，细节见路线图 M20。写的时候发现：
  - 有生命的星球上氧囊草本来就长，退出标准的星球得是没有生命的。
  - 冰冻星球一般是寒冷加强紫外两道，抗紫外的基因母星的菌里没有，只编辑抗冻进不去；先把大气加厚，紫外这一道就没了。手册里冰冻星球写的是"寒冷、强紫外"，和这一致。
  - 基因库是全服的，别的测试也测北极冷杆菌，等待条件要看这台测序仪自己的产出格，不能看基因库。
- 测试：单元测试全过；游戏内测试 228 个全过（新加 9 个：`LinkageGameTests` 6 个、`M20ExitGameTests` 3 个）。

### 从零开始的生存通关

- 原来打算"用开发脚本加速时间跑通主线"，做不到：开发脚本只会执行命令、点按钮、截图，不会自己挖矿、搭产线，靠命令摆出来的时间量的不是节奏。通关要人来玩。
- 改成让每一局自己记时间（`core.stats.Pacing`、`stats.PacingData`）：每个科技第一次研究完时主世界的游戏刻记进 `pacing.dat`，剧情节点的时间 `StoryData` 本来就记着。`/universe pacing` 列出几个关键节点是第几个小时到的，有目标的四段（蓝矩阵 4、跃迁引擎 10、第一片球壳 25、任务完成 40 小时，取自 `Progression.MILESTONES`）和模型比出倍数。作者或者测试玩家照常玩，玩完看一眼就知道哪段慢。
