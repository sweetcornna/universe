# ADR-0027 外星文明：种族、语言、声望、对话、礼物、公会

- 状态：已采纳（M15）
- 日期：2026-10-21

## 背景

- ADR-0020 给 M15 列的缺口：种族、NPC、语言、声望、对话、礼物、公会任务；种族的设定和台词等剧情讨论后定稿，先放占位。退出标准是"在空间站和据点里和 NPC 对话、学会单词、声望升一级"。ADR-0026 把知识石和聚落也挪到这里。
- 现状（2026-10-21 的提交 6460c17）：
  - 没有 NPC、种族、声望、外星语言。空间站只按种子生成，不存档，只知道自己是第几个恒星系；交易终端、任务板、船商、修理台、工具柜都是方块，没有人。
  - 恒星系唯一像"势力"的属性是经济（`core.trade.Economy`，派生键 `economy`）：七种经济、三档富裕。
  - 任务板每个空间站每天 3 个任务（送货、悬赏海盗、挖小行星、扫描物种），只给信用点和偶尔的导航数据、技术模块，不分公会。
  - 最接近"学单词"的是石碑教传送门符文（`portal.PortalGlyphs`，一块石碑教一个）。`core.procgen.NameGenerator` 能按音节拼出双语的名字。
  - 唯一像对话的是遇险货船的船长，在聊天栏给两个按钮。
- 无人深空的规则（nomanssky.fandom.com 的 Gek 页、gamerguides.com 的 Local Missions and Guilds 几页、twinfinite.net 的 Choosing the Right Answer、powerpyx.com 的语言攻略，2026-10-21 读）：
  - 三个种族，每个恒星系有一个主导种族，空间站和聚落里多是这个种族的 NPC。
  - 每个种族一套语言，一次学一个词：知识石一块一个，跟 NPC 对话、送礼也能学。认识的词在对话里显示成翻译，不认识的显示成外星文字。
  - 对话：NPC 说一段话、给几个选项，只有一次机会。选对了给奖励、加声望，有时教一个词；选错了什么都没有，可能掉声望。选对的诀窍是按这个种族看重什么来选。
  - 声望按种族、按公会分开记，大概十几档，从负数开始。声望高了奖励更好、能请 NPC 教词，种族的任务、公会的任务都加声望；打掉骚扰聚落的海盗、给 NPC 送礼也加。
  - 三个公会：商会、佣兵会、探险会。空间站的任务代理给公会任务，公会使者在某一档以后送礼。
- 现实里能借的（ADR-0025）：
  - 破译一种没见过的文字要靠对照的文本和上下文：罗塞塔石碑有希腊文对照，线形文字 B 是文特里斯排了符号表、从地名猜出来的。
  - SETI 设想的第一次接触先讲数学和物理：1974 年的阿雷西博信息用二进制写了 1 到 10、组成 DNA 的五种元素（氢、碳、氮、氧、磷）。这些概念哪个文明都能推出来。
  - 人类学里送礼是建立关系的办法，收了礼要回礼（莫斯《礼物》，1925）。

## 决定

M15 分两块做，每块做完验收、提交。

### 一、种族和恒星系

- 三个种族，id 和占位的名字如下。外形、名字、来历、台词都是占位，等剧情讨论后定稿；系统只认 id 和"看重什么"。

| id | 占位名 | 看重 | 外形（占位） |
| --- | --- | --- | --- |
| `trader` | 商旅族 / Traders | 利：公平的买卖、赚钱 | 矮，1.3 格，鸟一样的喙 |
| `scholar` | 学者族 / Scholars | 知：新发现、技术、数据 | 高瘦，2 格，有外壳 |
| `warden` | 戍卫族 / Wardens | 勇：力气、胆量、守信 | 壮，2.2 格，有甲 |

- 每个有空间站的恒星系按新的派生键 `civilization` 定一个主导种族，三个种族各占三分之一。母星系固定是商旅族，让玩家先遇到最好打交道的。星图、恒星系信息、交易终端的标题上写着主导种族。

### 二、语言

- 每个种族 64 个词，概念大家一样（`core.civ.Lexicon`，概念的意思写在语言文件里），外星的写法按派生键 `language/<种族>` 用音节拼出来，三个种族的音节表不一样（商旅族短促、学者族多辅音、戍卫族多长元音），同一个世界里固定不变。
- 每个玩家按种族记认识哪些词（每个种族一个 64 位的掩码）。
- 前 8 个是数学和物理的词：一、二、三、氢、碳、氧、星、光。这些一开始就认识（照阿雷西博信息的思路，哪个文明都能推出来）。
- 学新词的办法：
  - 知识石（新地标）：一块教一个，每块每人一次。
  - 对话选对了：从这段话里没认识的词里猜出一个（上下文）。
  - 送合心意的礼物：NPC 回教一个词。
  - 声望到"认识"以后，每个 NPC 每天能请教一个词。
- 对话里认识的词显示成翻译（加亮），不认识的显示成外星写法。认识的词越多，越容易看出 NPC 想要什么。

### 三、NPC

- 实体 `alien_npc`，不存档，玩家走近时由管理器按位置的种子放出来（和海盗、守卫机一样），走远了收走。打不死：挨打掉 5 点那个种族的声望，NPC 躲开。
- 角色：
  - 访客：一段对话（见下），能送礼、请教词。
  - 技术商：卖技术模块。
  - 公会使者：公会任务、公会的礼物（第二块做）。
- 放在哪：
  - 空间站 4 个：2 个访客（一个主导种族，一个随机种族，每天换人）、1 个技术商、1 个公会使者，站位固定在大厅里。
  - 交易站 1 个访客，站在交易终端旁边。
  - 聚落（新地标）3 个：2 个访客、1 个技术商。
- 名字按种子用这个种族的音节拼，头顶显示名字和角色。

### 四、对话、礼物、声望

- 对话界面照兴趣点的文字界面（逐行显示），上面是 NPC 的名字、种族、你在这个种族的声望档。中间两段：一段外星话（认识的词翻译出来），一段旁白描写 NPC 的样子；下面三个选项。另有固定按钮：送礼、请教一个词、离开；技术商多一个"看货"，公会使者多"公会任务"。
- 对话的题目（`core.civ.Encounter`）：每个题目有一段外星话（嵌 3–5 个词）、一段旁白、三个选项，三个选项分别对上"利""知""勇"。选中这个种族看重的那个算对。题目和选项的文字是占位，先写 6 个题目，剧情讨论后重写、加多。
  - 选对：声望 +3，从这段话里学一个词，给一份奖励：商旅族给信用点或贸易品，学者族给导航数据、勘测数据，偶尔一个技术模块，戍卫族给守卫机残骸、电磁线圈，偶尔一个武器模块。
  - 选错：声望 −1，没有奖励。
  - 每个 NPC 每人每天一次。
- 礼物：把手里的东西送出去。每个种族喜欢几类东西：商旅族喜欢值钱的贸易品，学者族喜欢数据、化石、遗物，戍卫族喜欢守卫机零件、武器。合心意的声望 +2、回教一个词；不合心意的收下，声望 +0。每个 NPC 每人每天收一次。
- 声望按种族、按公会分开记，每人每项 −20 到 100，从 0 开始：

| 声望 | 档 | 效果 |
| --- | --- | --- |
| −20 到 −6 | 敌视 | NPC 不对话、不卖东西；这个种族的空间站买东西贵 10% |
| −5–9 | 陌生 | 从 0 开始，答错一两次、打一下还不至于翻脸 |
| 10–24 | 认识 | 能请教词 |
| 25–44 | 熟客 | 这个种族的空间站买东西便宜 5%；技术商多一档货 |
| 45–69 | 朋友 | 便宜 10% |
| 70–100 | 至交 | 便宜 15%；技术商最好的一档 |

- 发现界面加一页"文明"：三个种族的声望和档、认识几个词，点进去看词表（外星写法、意思）；第二块再加三个公会的声望。

### 五、知识石和聚落

- 两种新地标（`core.poi.LandmarkType` 往后加，各用自己的派生键）：
  - 知识石：一块刻字的石柱，网格 500 格、一格五成，占地半径 2。任何星球都有，教这个恒星系主导种族的词。
  - 聚落：三四间这个种族的小屋、一台交易终端、一块知识石、3 个 NPC。网格 1400 格、一格四成，只在有大气、不荒芜的星球。
- 只在以后生成的区块里出现。
- 无人深空后来的聚落经营（当监督者、盖房子、收税）不做。

### 六、公会（第二块）

- 三个公会：商会、佣兵会、探险会，声望档的分界同上，档名用"新人、会员、资深、精英、大师"。
- 任务板的任务分到公会：送货、挖小行星归商会，悬赏海盗归佣兵会，扫描物种归探险会；新加两种：打掉几架守卫机（佣兵会）、去这个恒星系某颗星球上的一处地标（探险会）。
- 完成任务：公会声望 +3，这个恒星系主导种族的声望 +2。
- 公会使者每天给 2 个这个公会的任务，档越高报酬越高；每升一档能来领一次礼物。
- 技术商每天 3 样货，从这个种族的模块池里抽（商旅族偏飞船和货舱，学者族偏扫描和外骨骼，戍卫族偏武器），声望档决定能抽到多好的；按声望打折。

### 存档和多人

- 每人一份 `CIVILIZATION` 附件（死亡后保留，同步给本人）：三个种族和三个公会的声望、每个种族认识的词、碰过的知识石、今天和哪些 NPC 说过话。
- 主导种族、语言、NPC 都按种子算，不存。
- 所有判定在服务端，客户端只显示。

### 七、实现时的改动（第一块，2026-10-22）

- 陌生从 −5 起。原来起点 0、低于 0 就敌视，第一次答错就翻脸，NPC 连礼都不收；现在 −6 以下才敌视，答错一两次、打一下还是陌生。
- 声望折扣只管买：在这个种族主导的恒星系里，空间站和交易站的终端买东西都按档打折或加价，卖出不变。
- 知识石挖不掉（没有掉落）。读过的记录按"星球@坐标"记，能挖走就能换个地方放下接着学。生成在后台线程跑，主导种族直接用 `Race.dominant(恒星系)` 算。
- NPC 的位置：
  - 空间站大厅有 4 个固定站位（`StationLayout.NPC_SPOTS`）。访客的种子带日期，每天换人；技术商、公会使者不换。
  - 交易站要站位 3 格内有交易终端才放人，地标落在湖里没盖起来时不会凭空站个人。
  - 站位头上是屋顶时往下找地板。
- 奖励换成物品：贸易品给打捞旧部件；技术模块是随机一个 C 级的外骨骼或工具模块；武器模块是 C 级的武器校准。
- 礼物从主手送一个。"值钱的"另外算上金锭、钻石、绿宝石、下界合金锭；带食物组件的算吃的。
- 同一个 NPC 两秒内只扣一次声望，连发的武器一秒能打十下。
- 对话界面：数字键 1–3 直接选；外星话后面写"认识 x/y"；NPC 不在了或者离开 8 格就关上。
- 聚落的样子：商旅族是羊毛台阶搭的帐篷和木货摊，学者族是白混凝土和整块玻璃的屋子，戍卫族是 7×7 的深板岩砖石堡。半径 9 以内的地面压平，9 到 12.5 慢慢接回原来的地形。
- 调试命令 `/universe civ`：`status`、`standing <种族> <值>`、`teach <种族> [n]`、`newday`、`reset`。
- 技术商的货（`core.civ.TechMerchant`）先写好了：每天 3 样，七成从本族擅长的模块里抽；熟客、朋友好一档，至交好两档、最后一样至少 A 级。界面在第二块接上。

### 八、实现时的改动（第二块，2026-10-22）

- 技术商：对话里点"看货"打开货单，三样货的种类和数值按 NPC 种子加日期定，品级再看声望档，同一天升了档货还是那几样、只是更好。价钱照这个恒星系市场的模块价乘声望折扣；买模块不影响市场价，和交易终端一样。客户端把看到的价钱一起发过来，对不上（换了档、过了一天）就不卖，刷新货单。
- 公会使者只在空间站有，按 NPC 种子定是哪个公会。每天 2 个任务，从这个公会的任务种类里出；交付在使者那里或任务板都行，和任务板共用"手上只能有一个任务"。
- 新的两种任务（守卫机、探访）只有使者给，任务板不出，老世界同一天的任务板不变。守卫机任务地上的守卫机和太空的拦截机都算。探访的目标是同恒星系能登陆的星球（母星除外）上，离着陆点 1000 格内最近的观测站、废弃建筑、知识石或聚落；走到 16 格内算完成，地标在老区块里没盖出来也照样算。
- 任务记录没加字段：公会由任务种类推出来，探访的目标编码进原来的物品字段。
- 礼物一次领一档；连跳两档就领两次；掉档再升回来不再给。被除名的人使者不给任务，提示去任务板挽回。
- 报酬随公会档：新人 1 倍，会员 1.15、资深 1.3、精英 1.5、大师 1.75 倍（`core.civ.GuildMissions.rewardFactor`）。礼物是信用点和导航数据，资深起加一个这个公会擅长的模块（资深 B、精英 A、大师 S）。
- 调试命令加了 `/universe civ guild <公会> <值>`。

## 理由

- 三个种族、一个"看重什么"的规则、按种族的语言，是无人深空外星文明的骨架，照着做玩家一看就懂。种族的设定、台词属于剧情，按用户的要求单独讨论，系统只认 id 和看重的东西，以后换文字不动系统。
- 语言照现实里破译文字的样子做：先有数学和物理的共同语言，再靠对照文本（知识石）和上下文（对话、礼物）一个一个学。这样学单词不只是收集，认识的词多了，对话真的更容易选对。
- 声望能掉到负数、档位分开，打 NPC 会掉，送礼、选对、做任务会涨，和原作一样；退出标准要求的"升一级"（0 到 10）选对两三次就能到。
- NPC 不存档、按种子放，和空间站本身一样不进存档，也不会因为老存档没有 NPC 出问题。
- 公会挂在已有的任务板上，不另起一套任务。

## 后果

- 新的派生键 `civilization`、`language/<种族>`、`landmark/knowledge_stone`、`landmark/settlement`、NPC 的位置种子，都是新键，已有的宇宙不变。
- 每个玩家多一份附件；任务的记录多一个公会字段（老记录按任务种类补）。
- 立项书 §4.2 不用再改（ADR-0020 已经把外星文明放进范围）。
- 种族的外形、名字、台词、对话题目都是占位，和用户讨论后重写。

## 备选方案

- 一种通用语言：省事，但三个种族就只剩外形不同，学词也没有意思。不用。
- 用原版村民和交易界面：村民的交易界面按物品换物品，对不上信用点、声望和对话。不用。
- 声望只在后台算、不给玩家看：原作给看，玩家要知道离下一档还差多少。不用。
- NPC 存档：要处理老存档、空间站重建时重复，得不偿失。不用。
