# ADR-0013 先复刻戴森球计划和无人深空的核心玩法

- 状态：已采纳
- 日期：2026-10-17

## 背景

- 2026-10-17，M4 做到发现日志时，用户要求"先把戴森球和无人深空的玩法复刻过来"，并强调"一定要记得完成度要高"。
- 立项书 §4.2 把"NPC 文明、贸易经济、星际战争"列为非目标，玩法设计里战斗是 P2。这样做出来的探索只有"看"和"采"，缺了无人深空里推着玩家往前走的几样东西：废墟里捡升级、守卫机逼你别乱挖、把东西卖掉换钱买更好的装备。
- 戴森球计划这边，M3 做完了第一、二阶段的工业（蓝、红矩阵），后面的物流、化工、戴森球、终局都还没做。
- 本 ADR 把两款游戏的核心循环逐项和现状对照，列出缺什么，并据此重排 M4 之后的里程碑。

## 决定

### "核心玩法"指什么

两款游戏前 50 小时里玩家反复做的事，以及推着玩家去做这些事的系统。只借鉴玩法，名称、美术、音效全部原创（立项书 §4.2 仍然有效）。工作名：守卫机（对应哨兵）、信用点（对应单位）、勘探数据（对应纳米簇，已实现）、技术模块。

### 新的里程碑顺序

按玩家的成长顺序排：先让探索有回报（无人深空的地面玩法），再做中期的物流（戴森球计划），然后戴森球，再回到太空里的无人深空玩法，最后终局。

| 里程碑 | 内容 | 退出标准 |
|---|---|---|
| M4 星系探索 | 已完成的星图、跃迁、发现日志，加上兴趣点、技术模块和背包扩容、多功能工具的武器、守卫机 | 能跃迁到别的恒星系、登陆 4 种以上的星球；在星球上探索兴趣点拿到模块并装上；过度开采会招来守卫机 |
| M5 物流网络 | 三档传送带和分拣器、分流器、储液罐、化工和精炼、硅钛线、太阳能板、分馏塔、轨道采集器、两种物流站、黄紫矩阵、统计面板 | 跨星球自动供货的完整产线 |
| M6 戴森球 | 编辑器、弹射器和太阳帆、发射井和火箭、渲染、射线接收站、临界光子、绿矩阵 | 建成第一层球壳并稳定供能 |
| M7 太空与贸易 | 空间站和交易、信用点、小行星带、飞船武器护盾和海盗、探索车、动物驯服和骑乘、基地传送、任务板 | 卖掉工厂产品买到飞船部件；打退一次海盗袭击 |
| M8 终局与内容 | 反物质、白矩阵、人造恒星、无限升级、蓝图、先驱者遗迹剧情、游戏内指南、数值平衡 | 一周目可以通关 |
| M9 Alpha | 性能、兼容性、多人测试、发布 | 公开发布 Alpha |

### "完成"的标准

一项玩法要满足下面全部条件才算做完，路线图才打勾：

1. 生存模式里拿得到：有配方或掉落，有对应的科技，`SurvivalProgressionTest` 走得通。
2. 有界面和反馈：HUD 或界面里看得到状态，有音效、粒子或动画，出错时告诉玩家原因。
3. 中英文都有，数据生成产出的资源齐全，`src/generated` 不手改。
4. 核心逻辑在 core 层，配单元测试。
5. 在开发客户端里按玩家的路径实际玩一遍，截图确认，发现的问题当场修。
6. 多人可用：服务端权威，状态能同步、能存档。

## 理由

- 两款游戏的乐趣各有一半来自"推着玩家往前走"的系统：戴森球计划是越来越长的生产链和物流，无人深空是兴趣点里的升级、守卫机的压力和交易。只做风景和采集，探索很快就没有目标。
- 把兴趣点和守卫机放在 M4：它们只依赖已有的星球生成和多功能工具，做完以后探索马上有回报，后面的物流、戴森球也有了材料来源（兴趣点里的蓝图、模块）。
- 贸易放在 M7 而不是 M4：信用点要有东西可卖才有意义，M5、M6 做完以后工厂有大量产品，正好需要出口。
- 立项书的非目标里"贸易经济、星际战争"改为"空间站贸易、守卫机和海盗的战斗在范围内"；NPC 文明、语言、外交、货船舰队仍然不做。原因是用户明确要复刻无人深空的玩法，而这几项里贸易和守卫机是循环的一部分，NPC 文明主要是美术和文本量，对循环的贡献小。

## 后果

- 路线图的 M4–M8 按上表重写，原来的 M8 Alpha 顺延为 M9；立项书 §4.2 加一条指向本 ADR 的说明。
- 战斗进入 M4（多功能工具武器、守卫机），需要一套简单的伤害、护盾和敌对 AI；M7 的海盗复用它。
- 每个里程碑的工作量变大，但按"完成"的标准逐项做完再打勾，不留半成品。

## 备选方案

- **先做完戴森球计划的全部工业，再做无人深空的玩法**：工业线最长，但探索会长时间没有回报，玩家在 M5、M6 里只有工厂可做；而且兴趣点、模块是工业材料的来源之一，晚做会让成长线断开。
- **完全照搬无人深空的经济和 NPC**：美术和文本量太大，和"方块为本"的支柱冲突，也会挤占工业的开发时间。
