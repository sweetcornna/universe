# ADR-0034 钓鱼、聚落和深空（M19）

- 状态：已采纳
- 日期：2026-10-23
- 相关：ADR-0013（"完成"的标准）、ADR-0025（以现实为底）、ADR-0026（星球生活）、ADR-0027（外星文明）、ADR-0031（贴图）、ADR-0032（第三轮对照）

## 背景

- 第三轮对照（ADR-0032）里无人深空这两年加的几块排进 M19：钓鱼（5.10 Aquarius）、聚落（Frontiers 和 5.70 Beacon）、化石（5.60 Relics）、深空（7.00 Cosmos）、科技的相邻和超频、局部危害（5.50 Worlds Part II）、重力枪（6.20 Remnant 的 Gravitino Coil）。做完这一个就是 1.0。
- 现在有的：
  - 水生动物（`AquaticCreature`）打了掉异星鱼肉，没有钓鱼。
  - 三个种族的聚落是兴趣点（`LandmarkType.SETTLEMENT`），只能对话、交易、学词，没有经营。
  - 化石坑出三种化石，只能卖。
  - 太空里有小行星带、废弃货船、空间站，飞船在太空里不能下船。
  - 技术模块各算各的（`TechBonuses` 同种取最好的三个相加），摆在哪一格都一样。
  - 天气只有风暴；海盗只在太空里打。
- 原作的资料：官网的更新说明（Beacon、Relics、Cosmos），Miraheze 维基的钓鱼、鱼、鱼饵页，媒体对 Aquarius、Worlds Part II、Remnant 的报道。原作的鱼有 169 种，分普通到传说四档、小中大巨四种个头，有的只在白天、夜里或风暴里出，深水多出大鱼；钓到的重量记进图鉴；任何能吃的东西都能当饵，另有六种专门的饵。

## 决定

### 一、钓鱼

- 钓鱼器：多功能工具的附件（`ToolWeapon.FISHING_RIG`，工具模式 `ToolMode.FISHING`），装法和武器一样。研究"钓鱼"（交物品的科技，在电磁学后面）解锁，装配机里做：钛合金 2、磁线圈 2、电路板 1（没有这几样就用同档次的现有材料，写进结果）。
- 甩竿：钓鱼模式下右键，浮标飞出去，最远 24 格，落在水或酸液上才算（熔岩不行）。再右键收回来。
- 等鱼咬钩：8–20 秒。鱼来之前 2–4 秒，水下有一条半透明的鱼影朝浮标游过来（用那种鱼的图标画，按水的颜色压暗）。咬钩时浮标往下一沉、溅水、响一声，25 刻内右键就钩住，晚了鱼跑掉。
- 收线：钩住以后按住右键收线，松开放线。屏幕下方一条张力条、一条进度条：
  - 张力在绿区（0.25–0.8）里时进度涨满速，过高涨一半，过低不涨。
  - 按住时张力按鱼的力气往上走，松开时每刻降 0.04。鱼隔一阵猛冲一次，冲的时候张力往上跳、进度往回掉。
  - 张力到 1 线断（饵没了，鱼跑了）；张力贴着 0 超过 2 秒鱼脱钩。进度满了钓上来。
  - 普通的小鱼五六秒，传说的大鱼二十秒上下。和平难度不玩这一段，咬钩就钓上来。
  - 判定都在服务端：客户端只报"按着还是松开"，服务端算张力和进度，每 5 刻同步一次，客户端在中间插值。
- 鱼：96 种，分 8 种水域，每种水域 12 种（普通 5、少见 4、稀有 2、传说 1）：
  | 水域 | 在哪 |
  |---|---|
  | 淡水 | 星原、林地、高地、河谷、湿地的水 |
  | 暖水 | 雨林、菌林的水，灼热星球上的温泉 |
  | 近海 | 海滩、海洋，水深不到 12 格 |
  | 深海 | 深海群系，或者海洋里水深 12 格以上 |
  | 冰下 | 冰洋、冻原、雪原、冰川、雪峰的水，冰冻星球 |
  | 酸水 | 酸海、毒沼的酸液，毒雾星球 |
  | 暗河 | 浮标那一格看不到天（洞里的水） |
  | 奇异 | 奇异星球和辐射星球上的水 |
  - 主世界照原版群系对过去：海洋、深海、河、冷的、热的、洞里的水各归各的一类。
  - 每种鱼带几个条件：时间（不限、白天、夜里）、天气（不限、风暴）、水深（不限、浅、深）。每种水域里有 2 种只在夜里出、1 种只在白天、1 种只在风暴里。
  - 个头：小（0.05–0.8 千克）、中（0.8–6）、大（6–40）、巨（40–400）。重量在个头的范围里随机，水越深越偏重。
  - 每颗星球的鱼不一样：照星球的种子从对得上的水域里挑，普通的全有，少见的四分之三，稀有的一半，传说的三成。同一种星球，换一颗钓到的也不全一样。
  - 鱼照现实的样子设计：冰下的鱼体内有抗冻蛋白、长得慢、个头大；酸水里的是嗜极生物，壳厚、颜色暗；暗河的没眼睛、颜色淡；深海的会发光。名字照图鉴的叫法起（"蓝鳍溪鲦"这样），不起"幻影之鱼"这种。
- 钓上来的东西：鱼 87%，杂物 10%（锈蚀零件、缠结的藻团、破损的储罐），漂流瓶和密封补给舱 2.5%，技术模块 0.5%。
  - 漂流瓶：打开后在这颗星球上标出一个附近的兴趣点（和导航数据一样）。
  - 密封补给舱：开出一份补给（按兴趣点补给箱的表）。
  - 技术模块：随机一种多功能工具或外骨骼的 C、B 档模块。
- 鱼饵：工具上一个饵格（数据组件），潜行右键（钓鱼模式下）打开。每钩住一条用掉一个。
  - 能吃的东西都能当饵：等鱼的时间 ×0.8；做好的菜（`DishItem`）×0.6，少见以上 +10%。
  - 六种专门的饵：
    | 饵 | 效果 |
    |---|---|
    | 腥饵 | 等鱼的时间减半 |
    | 亮片拟饵 | 少见、稀有的概率翻倍 |
    | 深水坠饵 | 大的、巨的概率翻倍，重量偏重 |
    | 夜光饵 | 夜里的鱼白天也会咬（概率减半），夜里翻倍 |
    | 静电拟饵 | 风暴里的鱼不下风暴也会咬（概率三分之一） |
    | 星核饵 | 传说的概率 ×4 |
  - 饵在营养处理器里做（腥饵用鱼肉和异星肉，星核饵要稀有的鱼和能量碎片之类的贵东西），配方写进结果。
- 放生：拿着鱼对着水右键，鱼跳回水里。接下来 3 次甩竿等鱼的时间减半，少见以上的概率 +15%。图鉴里记放生了几条。
- 图鉴：发现日志里加一页"钓鱼"，按水域排 96 格。钓到过的写名字、最重的一条多重、在哪颗星球钓的、钓了几条；没钓到过的是剪影，写水域、档次和条件（时间、天气、水深）。记在玩家身上。
- 鱼是物品，每种一个（`universe:fish_<名字>`），能叠，生吃给一点饱食度，有 `universe:fish` 标签和按档次的标签（`universe:fish/common` 等），原版的 `#c:foods/raw_fish` 也算。价钱按档次和个头：普通的小鱼 20 信用点左右，传说的巨鱼 6000 左右。
- 海鲜菜：`Dish` 往后加烤鱼排、鱼汤、生鱼片拼盘、熏鱼、深海炖菜（回氧气）、冰鱼汤（保暖）、传说鱼宴（危害防护回满），营养处理器里做，用鱼的标签。
- 捕鱼笼：一个方块，整个泡在水里才干活。每 3 分钟按那里的水域出一条（只出普通和少见，杂物 15%），饵格里有饵时快一倍，9 格输出，能用漏斗和分拣器取。
- 给聚落用的接口：`fishing.Fishing#pondCatch(ServerLevel, BlockPos, RandomSource, int grade)` 返回一条鱼（或杂物），`grade` 是鱼塘的档次，越高越容易出好的。

### 二、聚落

- 认领：没有总督的聚落，聚落终端里多一项"接管"。和这个种族的声望到"相识"以上，交一份建设物资（金属板 30、碳纳米管之类的中期材料若干，写进结果）就成了总督。一个人最多管 4 个，一个聚落只有一个总督。可以辞去总督。
- 数值（`core.settlement`）：人口、住房上限、幸福（0–100）、生产力（0–100）、威胁（0–100）、储备（生产攒下的东西）、欠款（信用点），按建筑和数值算出聚落的等级 C、B、A、S。
- 聚落的"一天"按 24000 刻算，不管星球自己的昼长：
  - 按生产力出产选定的产品，放进储备；储备满了不再涨。
  - 交维护费：每座建筑每天 40 信用点，先从储备里折算，不够记欠款。有欠款时幸福每天 −5。
  - 幸福向建筑给的基准值靠；低于 25 每天走一个人，高于 70 而且有空房每天来一个人。
  - 威胁每天涨 生产力 / 10 + 人口 / 4，瞭望塔、炮台压低。
- 建筑：聚落周围 16–30 格的一圈留 8 块地基，接管时标出来（地面整平、铺一圈边）。建筑有十种：
  | 建筑 | 占地 | 作用 |
  |---|---|---|
  | 总督办公室 | 5×5 | 第一个盖，有了它才有管理界面和每天的决定 |
  | 住宅 | 5×5 | 住房 +3 |
  | 农场 | 7×7 | 生产力 +10，能出食物 |
  | 工坊 | 7×5 | 生产力 +15，能出金属板、零件 |
  | 酒馆 | 7×7 | 幸福 +12 |
  | 市场 | 7×7 | 每天收一笔信用点，有公会使节 |
  | 瞭望塔 | 3×3，12 格高 | 每天给一份附近兴趣点的导航数据，威胁每天 −5 |
  | 防御炮台 | 3×3 | 海盗来时朝它们开火，威胁每天 −3 |
  | 着陆坪 | 9×9 | 能停船，生产力 +5 |
  | 鱼塘 | 7×7 | 每天出鱼（`Fishing#pondCatch`） |
  - 每种建筑能升三次：C → B → A → S，作用依次 ×1、×1.5、×2、×3，外观多一层细节。
- 施工：在总督办公室选一块地基、选一种建筑，地基上立起施工终端。分三段，每段先交齐材料，再等 5 分钟；第一段打地基、搭脚手架，第二段起框架，第三段完工。完工后去施工终端点"开张"，放一轮烟花。建筑按种族的风格用方块搭（照 `SettlementStructures` 的写法），不是贴图。
- 决定：总督办公室每天一个，四类：请愿、纠纷、新来的人、政策。每个决定 2–4 个选项，改数值、给东西（信用点、材料、声望、单词、新居民）。表里先写 24 个，字写短、写具体，和别的游戏里这类提示一个口气。
- 生产：每个聚落能选一种产品，按种族和已有的建筑开放：商旅族出贸易品和信用点，学者族出数据、导航数据，戍卫族出弹药、金属；农场出食物，工坊出金属板和零件，鱼塘出鱼。储备在管理界面里取，或者直接卖掉。
- 海盗来袭：
  - 威胁到 100 时（或者每天按威胁算一个概率），夜里来一波海盗：3–6 架海盗战机从天上飞来扫射建筑，2 分钟内打下全部算守住。
  - 守住：幸福 +10，威胁清零，给一笔信用点。没守住：两座建筑受损（要交材料修，修好前不起作用），幸福 −15，储备被抢走三成。
  - 总督不在 256 格内时不真打：按炮台、瞭望塔的防御值和来袭的规模直接算输赢。
  - 海盗战机原来只在太空里飞（`PirateFighter`），在星球上要能飞、能扫射地面目标。
- 管理界面：概况（数值、等级、最近的事）、建筑（列表、升级）、施工、决定、生产。另有一张"我的聚落"表，四个聚落的数值和欠款在一起看。
- 居民：聚落里站着的外星人跟着人口多起来（照现有的 `NpcSpawner`，最多站满预留的位置）。
- 多人：只有总督能管，别人进得来、看得到。

### 三、化石

- 骨头部件：8 个古生物类群 × 5 个部位 = 40 种。
  - 类群：巨兽（大型食草）、掠食兽、长颈兽、翼兽、巨蠕、甲壳兽、海兽、奇异种。
  - 部位：头骨、颈椎、胸廓、四肢、尾骨。巨蠕的"四肢"是体节环。
  - 每个类群有自己的稀有度：巨兽、掠食兽、长颈兽常见，翼兽、海兽少见，巨蠕、甲壳兽稀有，奇异种很稀有（只在奇异星球）。
- 哪里挖：化石土的战利品加上骨头部件（按星球类型偏重不同的类群；原来的三种化石照旧）。新兴趣点"古生物发掘场"（`LandmarkType` 往后加）：几顶帐篷、一个收藏家、一大片化石土，旁边睡着石哨兵。
- 石哨兵：一种浮着的石头守卫，在发掘场挖了 3 块以上化石土就醒过来，扔石块，血少时冲过来自爆。打下来掉稀有的骨头。
- 展台：
  - 化石底座：放一块骨头，任何部位都行。
  - 骨架展台：放五个部位，每格只收对应的部位，五格不分类群。五格都放上就拼成一副完整的骨架，照部件起个名字（比如"长颈掠食兽"），显示在展台上。
  - 骨头画成立体的：每个类群每个部位一组方块拼的模型（像实体模型那样用代码搭），共用一张骨头的贴图。不同类群的部位拼在一起各管各的位置和大小，接得上。
- 封装：骨架展台的界面里点"封装"，变成一件化石展品（物品，记着五个部件和名字），能叠起来带走；拿着展品对着空的骨架展台右键就摆回去。
- 收藏家：空间站和发掘场里有（`NpcRole` 往后加）。
  - 收展品：价钱 = 部件价钱之和 × 完整 2 倍 × 五件同一类群再 1.5 倍。
  - 换骨头：交 3 块不要的，换 1 块指定类群、指定部位的。

### 四、深空

- 每个星系的太空里，按种子多几种兴趣点，飞近了在 HUD 上标出来：
  - 碎片带：三五十块漂着的残骸碎片（实体，和小行星一样能被飞船的采矿光束打），打碎掉废金属、合金板、电子元件，偶尔有技术模块。小块的能用引力抓取器抓。
  - 废弃前哨站：太空里一座用方块搭的小站（核心舱、气闸、走廊、仓库），没电，有补给箱、数据终端（给导航数据）、能拆的设备。
  - 太空残骸：60–120 格长的废船，用来拆。
- 拆残骸：
  - 残骸用几种方块搭：残骸舱板（拆下来是废金属）、残骸导管（零件，拆的时候结构 −8）、残骸货舱（开出补给）、反应堆屏蔽层（−5）、反应堆芯（最值钱，拆下来 −30）。别的方块拆了 −1。
  - 残骸有结构完整度，从 100 开始。进到残骸附近时 HUD 上显示。低于 30 开始报警（红光、警报声）；降到 0 或者反应堆芯被拆下来，20 秒后熔毁：残骸剩下的部分炸掉，24 格内的人受重伤。
  - 拿到反应堆芯算拆完一艘残骸。
- 牵引光束：飞船的新技术模块（`ModuleType` 往后加，装在驾驶台）。开着时把 40 格内掉落的物品和小块碎片吸过来，收进飞船的货舱（`ShipCargoContainer`），货舱满了就不吸。用引力抓取器扔过来的东西也收。
- 抛货：飞船货舱界面里，选一格点"抛出"，或者"全部抛出"；东西从船尾飘出去。
- 出舱：飞船在太空里时，驾驶的人按潜行就能下船。船停在原地（速度清零，不漂）。人在外面失重，照空间站里失重的操作（跳、潜行上下），外骨骼的喷气背包能往六个方向推。太空的真空和寒冷照常扣防护。对着自己的船右键回到座位上。

### 五、科技的相邻和超频

- 技术格排成网格：外骨骼 12 格（4 列 3 行，没开的格子照旧锁着），多功能工具 8 格（4 × 2），飞船驾驶台 6 格（3 × 2）。
- 相邻：上下左右挨着的同一种模块（同一个 `ModuleType`）互相加成，每挨一个 +5%，最多 +20%。
- 超频格：外骨骼 3 个，多功能工具 2 个，驾驶台 2 个，位置照种子固定（外骨骼按玩家，多功能工具按工具自己的种子，驾驶台按方块的位置），放进去的模块 ×1.25，和相邻的加成相乘。
- 同一种模块还是取最好的三个，按加成以后的数值比。
- 界面：超频格画一圈橙色的光，相邻的同种模块之间画一道连线；悬停写出"相邻 +10%，超频 ×1.25"。
- 计算放在 `core.tech`，有单元测试。

### 六、局部危害

- 间歇泉：世界生成的地物，冰冻、毒雾、灼热、奇异星球上有水或冰的地方，一处 2–5 个喷口。
  - 安静 40–90 秒，响 3 秒（冒泡、地面轻震），喷 5 秒：15 格高的水汽柱。
  - 柱里的东西往上抛（能借它跳上高处），按星球扣防护：灼热星球烫、毒雾星球毒、冰冻星球冻。
  - 喷口边上的结壳能挖，出硫磺或冰晶之类的（按星球）。
- 火山喷发：灼热星球的火山坡、熔岩海、玄武岩原、灰烬荒原上，偶尔在玩家附近发生。先 3 秒"地面在震动"，再 20 秒里每秒落一两颗熔岩弹，落在 8–40 格外，着火、烫伤 3 格内的人，不炸方块。
- 孢子云：毒雾星球的毒沼、菌林、异形密林里，偶尔飘来一团孢子云（半径 5 格，60–90 秒），顺着风飘。云里毒性防护掉得快 4 倍，画面发绿。风暴时多。
- 尘卷风：有大气、有风的星球上的荒漠、尘埃盆地、硫磺平原、方山台地、峡谷、风化平原里，偶尔起一个尘卷风（半径 3 格，12 格高），慢慢游走，把掉落物、生物、人卷起来转几圈甩出去。不直接伤人，摔下来照算。
- 聚落（被认领的）和基地信标 32 格内不发生这些。频率能在世界设置里调（游戏规则），关掉就都不出。
- HUD 上给提示，声音照 ADR-0029 合成。

### 七、重力枪

- 引力抓取器：多功能工具的附件（`ToolWeapon.GRAVITY_COIL`，`ToolMode.GRAVITY`），研究后在装配机里做。
- 按住右键抓准星对着的东西，16 格内：掉落物、残骸碎片、个头不超过 1.5 格的生物（不抓玩家、头目）、守卫机里的无人机、黑雾的突袭者。抓着的东西悬在面前 3 格，跟着视线走。
- 松开右键轻轻放下；抓着时左键扔出去，每刻 3 格。扔出去的东西撞到别的生物按速度和重量伤它（掉落物 2、小生物 6、无人机 10 点上下）；被扔的守卫机晕 3 秒。
- 潜行左键：朝前方 8 格的锥形里把没固定的东西全推开。
- 在太空里把打捞物扔向开着牵引光束的自己的船，就收进货舱。

### 八、"完成"的标准和验收

- 每一项照 ADR-0013：生存模式拿得到（研究、配方、兴趣点），有界面和反馈，中英文由数据生成，核心逻辑在 `core` 里有单元测试，游戏里验过，多人时服务端判定。贴图照 ADR-0031 在 `tools/textures/` 里写配方，声音照 ADR-0029 在 `tools/sounds/` 里合成。
- GameTest：钓鱼的条件和收线、饵用掉、放生、捕鱼笼出鱼；接管聚落、施工三段完成、决定生效、海盗来袭按防御算输赢；骨架展台拼完整、封装再摆回去、收藏家换骨头；残骸拆到熔毁、牵引光束收进货舱、抛货、出舱再回船；相邻和超频算对；间歇泉把东西抛起来、孢子云里毒性掉得快；引力抓取器抓起来扔出去。
- 无头验收：退出标准里的四件事（在三颗星球钓到不同的鱼记进图鉴；接管聚落、盖完一个建设项目、守住一次海盗来袭；拼出一副完整的骨架；拆完一艘残骸）。

## 理由

- 钓鱼照原作做成附件加收线，而不是原版钓竿：原版钓鱼只有"等着、点一下"，原作的乐趣在找不同的水域、时间、天气和饵，收线也要手上有点功夫。
- 鱼按水域和星球种子挑，而不是每颗星球全随机：玩家能从图鉴的条件里推出去哪找，换星球又有新的。
- 聚落用现成的兴趣点：三个种族的聚落已经在世界里了，接管它比另外造一套"聚落生成"省事，也和原作一样是"接手一个已经有人住的地方"。
- 聚落的一天按固定的刻数：星球的昼长从几分钟到永昼都有，按星球算会差几十倍。
- 骨头用代码搭立体模型：40 个部位、几百万种拼法，用贴图拼不出立体的骨架；方块拼的骨头和原版的实体模型一个风格。
- 残骸用方块搭：拆就是挖方块，和原版的手感一样，结构完整度按挖了什么算。
- 相邻和超频只改算加成的那一步：模块、格子、界面都还是原来的，存档不受影响。

## 后果

- 存档：新的世界数据（聚落、残骸、深空兴趣点）、玩家数据（钓鱼图鉴）、数据组件（饵、超频格的种子、化石展品）。旧档读得出来。
- 网络协议到 34。
- `ToolWeapon`、`ToolMode`、`LandmarkType`、`NpcRole`、`ModuleType`、`Dish` 往后加（只往后加）。
- 价钱表（`RawValues`）改成各个玩法把自己的表并进来。
- 新的贴图三百张左右（96 种鱼用参数化的配方画），新声音几十个。

## 备选方案

- 用原版的钓竿和钓鱼的战利品表，按星球换表：没有收线、没有饵、没有图鉴的条件，不是原作的玩法。
- 聚落另外生成"空的聚落地"：玩家看不到现有的外星人聚落和新玩法的关系，世界里也多一套东西。
- 化石展品用贴图拼：平的，摆出来不像骨架。
- 出舱做成真的轨道运动、船会漂走：照 ADR-0025 按可玩性收住，船停着不动。

## 结果（2026-10-24）

七项都做了，五块分给五个子代理并行写，合起来以后统一构建、跑测试、无头验收。GameTest 159 个全部通过。和上面写的有出入的地方：

- 钓鱼：研究"钓鱼"交 4 块异星鱼肉、6 个磁线圈。钓鱼器照原计划在装配机里做（钛合金 2、磁线圈 2、电路板 1）。六种饵在营养处理器里做：腥饵是异星鱼肉加异星肉，亮片拟饵是生物凝胶加金粒，深水坠饵是异星肉加铁粒，夜光饵用伽马根，静电拟饵用雷击石，星核饵要一条稀有的鱼、2 块能量碎片和 1 颗活珍珠。捕鱼笼是工作台配方（铁栏杆、铁锭、箱子）。钓上来的比例照原计划：鱼 87%、杂物 10%、漂流瓶 1.5%、补给舱 1%、模块 0.5%。
- 聚落：接管交 30 钢材、8 碳纳米管、8 电路板（原来写的"金属板 30"换成了钢材，中期就做得出）。除了聚落终端，广场上的交易终端蹲下右键也能打开聚落界面。被接管的聚落 40 格内不发生局部危害。
- 化石：研究"古生物学"交 4 块贝壳化石、2 块节肢化石。化石底座、骨架展台是工作台配方，用石头，展台嵌一块铜锭。化石土 40% 出一块骨头。石哨兵在同一处发掘场挖到第 3 块化石土时醒，打下来掉 1–2 块稀有的骨头。
- 深空：恒星系里的残骸、前哨站、碎片带按种子排位置，玩家飞到 450 格内才真正搭出来，状态（搭没搭、完整度、清掉了哪些碎片）存在 `deep_space.dat`。出舱是 X 键，牵引光束是 C 键。打捞物回炉只做到"不亏"：一件打捞物在进度模型里按一个矿算，回炉出来的不能比开矿便宜，反应堆芯只卖不回炉。
- 科技布局：多功能工具按档次只有 4–8 格，超频格只落在它有的格子上；外骨骼在全部 12 格里挑，落在没解锁的格子上的要等修好掉落舱才用得上。局部危害的频率是游戏规则 `universe:local_hazards`（0–300，默认 100，0 关掉）；基地信标 32 格内不发生。间歇泉喷口边的结壳按星球出硫磺、盐、冰晶。
- 手册：钓鱼、管理聚落、古生物学、深空各加了一章，求生一章加了"局部危害"和"技术格的排法"两页。
- 开发命令：`/universe settlement goto`、`/universe fossil goto` 传送到最近的聚落、发掘场边上，验收脚本用。重力枪的推开动词叫 `shove`：叫 `push` 的话被开发脚本自己的 `push`（按界面按钮）先匹配上，永远轮不到。
- 游戏内测试的几个坑写进了技术架构 §4：测试世界里没有测试结构的地板，要自己铺；`makeMockServerPlayerInLevel` 的假玩家收不了本模组的负载，改用自己包一层的假连接（`gametest.QuietPlayers`）；会飞的战机在测试框里撞屏障乱弹，改到几千格外的真实地面上测。
- 验收时修好的旧问题：气态巨行星的世界尺寸是 0（表示不限），但 M14 的星球边界把它真设成了 0，整颗星球都在边界外：实体不走、人碰不了方块、一进去就提示"在星球边界外"。现在尺寸为 0 时用原版的默认边界，已经存成 0 的存档读进来时改回去。另外 M18 蓝图的材料清单在生存模式下没拿蓝图时也一直画着（没预览过时的时间戳是 Long.MIN_VALUE，相减溢出），一并修了。
- 验收时还抓到一个本里程碑自己的问题：熔毁炸出来的残骸碎片带着速度，客户端每刻也调 `move`，26.x 默认只许服务端算，开发环境里客户端当场崩掉。碎片改成两边都算漂移，同原版的掉落物（技术架构 §4）。之前没撞上，是因为碎片带里的碎片原本不动。
- 网络协议版本到 34。
