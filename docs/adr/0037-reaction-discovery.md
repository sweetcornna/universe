# ADR-0037 化学反应：按投料认反应、化学手册和实验记录（M20）

- 状态：已采纳
- 日期：2026-10-27
- 相关：ADR-0025（以现实为底）、ADR-0035（1.x 的存档承诺）、ADR-0036（化学与生物研究）

## 背景

ADR-0036 的反应釜只有五条反应，玩家在界面上点一条，釜就照它做。两条的反应式和实际进出的物品对不上：接触法写着 2SO₂ + O₂ ⇄ 2SO₃，物品却是二氧化硫、氧和水进、硫酸出；费托合成写着 CO + 2H₂ → (CH₂) + H₂O，高温时一部分碳变成甲烷，多耗的氢不扣。

2026-10-27 用户看了退出验收后提出：反应不该只有这几条；给玩家一本指导书就行；反应式和物品完全一致；做成一个反应就解锁对应的配方，也能用别的办法拿到。问了两个问题，用户选了"按投料认反应"，反应数量交给我定。

## 决定

### 一、反应釜按投料认反应

- 反应釜有两种用法。**自由投料**：原料格不限物品，玩家把反应物放进去、催化剂放进催化剂格、调好温度压强，釜认出是哪条反应就开始反应。**选定配方**：在界面左边的列表里选一条已经解锁的反应，原料格只收这条的反应物，漏斗、分拣器能往里送，和以前一样能自动化。
- 认反应只看原料格里有哪几种物品（不看顺序和数量）和催化剂格：
  - 反应物种类完全相同的反应只有一条，就是它；放错了或没放催化剂照样反应，只是慢（不放催化剂是 2%，和以前一样）。
  - 同一组反应物有几条反应时（一氧化碳加氢在铁上是费托合成、在镍上是甲烷化、在铜锌上是甲醇），按催化剂挑；没放催化剂或放的不对其中任何一条，界面上写"对得上 N 条反应，放催化剂挑一条"，不反应。现实里这几条也是靠催化剂的选择性分开的。
  - 认不出就写"认不出这组原料"。
- 每条反应的（反应物种类，催化剂）组合唯一，单元测试保证。
- 第一次在自由投料下做成一批，这条反应就**发现**了：全服记下（和研究、基因库一样全服共用），聊天栏提示"新发现 · 化学反应：甲醇合成"，手册里打勾，反应釜的列表里能选。选定配方只能选发现了的。

### 二、反应式和物品完全一致

- 一批用掉的物品数就是反应式里反应物的系数，做出的就是产物的系数，没有别的进出。反应式由反应物、产物和系数生成，界面、JEI、手册显示的都是同一个式子。
- 接触法改成 2SO₂ + O₂ ⇄ 2SO₃，三氧化硫成了物品；吸收另算一条 SO₃ + H₂O → H₂SO₄。
- 费托合成改成 2CO + 4H₂ → (CH₂)₂ + 2H₂O，一个精炼油按两节 CH₂ 算，不再按温度分出甲烷；甲烷化另算一条 CO + 3H₂ ⇄ CH₄ + H₂O（镍）。
- 每条反应按物品上的化学式检查原子守恒（单元测试）。别的设备的配方里，进出物品都是纯物质的也照样检查，对不上的改掉；带混合物（煤、原油、精炼油）或者没有化学式的不查。
- 单程转化率只管快慢：没反应的原料留在釜里接着反应，一批的进出不打折。

### 四、化学手册

- 一本书（物品），右键打开。左边按类分，右边一条一页：名字、反应式、催化剂、教科书的工况、反应焓（放热、吸热）、可不可逆、做成过没有。
- 研究了对应科技的反应列出来（上表最后一列）。没研究的写"？？？"和怎么拿到。发现了的（自由投料下碰巧做成的、读了实验记录的）没研究也列出来。
- 手册在工作台上用书和一个空瓶合成，研究"大气化学"以后就能做。

### 五、别的办法拿到配方

- **实验记录**：一张纸，写着一条反应。右键读了，这条反应就发现了（和做成一批一样）。出在废弃前哨站、废弃货船和太空残骸的箱子里；学者种族的商人卖。
- **研究**：研究只把反应列进手册，不直接解锁配方，还是要做成一次或者读实验记录。

### 六、存档

- 新的全服数据 `reaction_book`：发现了的反应，按名字存。
- 老存档：已经选了反应的反应釜读档后的第一刻把那条记成发现了（不在聊天栏说）；产量图（`ReactorKnowledge`）里做成过一批的反应也算，第一次读 `reaction_book` 时补上。
- `Reaction`、`Catalyst` 只往后加。接触法、费托合成的配方改了进出物品，老存档里选着它们的反应釜照新的做。

## 理由

- 按投料认反应就是做实验：照手册配料，做出来才算会了。同一组反应物靠催化剂分出不同产物，这是工业化学里真实的一课。
- 选定配方保留，自动化不受影响：认出来、做成过以后，整条产线和以前一样跑。
- 反应式由系数生成、物品数等于系数，显示和实际不可能对不上；原子守恒的测试防住以后加的配方写错。
- 全服共用和研究、基因库一致，多人时不用每人各做一遍。

## 后果

- 反应釜界面左边的五个按钮换成能滚动的列表（"自由投料"加发现了的反应）。
- `ReactionTest` 加原子守恒、组合唯一、各反应产量最高的温度落在工况里；化工厂、电解槽配方的守恒检查在单元测试里读数据生成的配方。
- 手册化学一章改写反应釜几页，加化学手册、实验记录。
- JEI 照旧列出全部反应釜配方。

## 备选方案

- 列表里只显示解锁了的反应，解锁靠研究、实验记录、交易：用户没选。
- 60 条以上：工作量大一倍多，多出来的大多没有产业链上的用处。
- 每个玩家各自发现：多人时要每人做一遍，和研究、基因库的做法不一样。
- 认反应时看配比（比如氢不够就做别的）：现实里配比决定转化率和选择性，不决定是哪条反应；这里配比只影响能做几批。

## 结果

2026-10-30 做完，代码在 `core.chem.reaction`（`Reaction`、`ReactionMatcher`、`ReactionBook`、`SpeciesThermo`）、`chem.reactor`、`chem.book`。

### 热力学数据

- 气相物质用 NIST 化学网络手册的 Shomate 方程（数据出自 Chase 1998，NIST-JANAF 热化学表第四版），焓和熵随温度变。
- 凝聚相和没有 Shomate 拟合的（硫酸、硝酸、硝酸铵、尿素、甲醇、乙烯、一氧化氮、二氧化氮、氰化氢、氯化氢、氯、硫、石墨）用 NIST 的 298.15 K 标准生成焓、标准熵和热容，热容按常数外推。它们多半只出现在不可逆的反应里，外推的误差只影响显示的反应焓。
- 精炼油按长链正构烷烃每节 CH₂ 的增量算（己烷到庚烷），一个精炼油两节；聚乙烯按乙烯聚合放热 93.6 kJ/mol、熵减 174 J/(mol·K) 算。
- 核对：合成氨在 450 °C、100 atm 的平衡氨含量算出 16.0%（手册 16.4%），300 atm 算出 31.8%（手册 35.5%，差的是高压下的非理想性，这里按理想气体算）。

### 别的设备的配方

`RecipeAtomBalanceTest` 查出化工厂四条对不上：

- 硫磺制硫酸原来是 2S + 2H₂O → 2H₂SO₄，缺 6 个氧。改成 2S + 3O₂ + 2H₂O → 2H₂SO₄，烧硫、转化、吸收合成一步。
- 可燃冰制石墨烯原来出 1 个氢。改成 2 个可燃冰出 2 个石墨烯、4 个氢（CH₄ → C + 2H₂），水合物里的水排掉：产物格只有两个，放不下水。这条记作豁免。
- 石墨烯（石墨加硫酸）、碳纳米管（石墨烯加钛）照戴森球计划不改，记作豁免：硫酸在现实的 Hummers 法里是插层剂和氧化的介质，用完成了废酸；钛是紫矩阵前要去别的星球的门槛，现实里不进纳米管，算作生长用的基底，提纯时烧掉的无定形碳也不回收。改成守恒要么不再耗硫酸，要么去掉钛，戴森球计划的进度门槛就没了。

豁免的理由写在测试的 `EXEMPT` 里，以后加的配方照样要守恒。

### 数值平衡

新反应里甲醇制烯烃再聚合的塑料只折 0.17 个矿（化工厂的是 0.33）。`BalanceTest` 的参考工厂不管研究顺序、只挑最便宜的配方，黄矩阵按它算便宜两成，紫矩阵那一档每个科技的中位价钱比前一档贵 6.04 倍，过了 6 倍的上限。反应釜要紫矩阵的"催化与化学平衡"，前三档用不上，所以和生物反应器一样不算进参考工厂，各档的数值回到 ADR-0037 以前。

### 测试

- 单元测试 1187 个全过：原子守恒、（反应物种类，催化剂）组合唯一、按投料认反应、教科书工况、各反应产量最高的温度、化工厂等配方的守恒。
- 游戏内测试 219 个全过，新加的：自由投料做成一批就发现、同一组原料按催化剂挑反应、没发现的反应选不了。
- 没做：化学手册界面和反应釜列表没有开客户端无头验收；M20 的退出标准没有整条走一遍。
