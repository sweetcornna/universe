第一个正式版。需要 **Minecraft 26.3**、**NeoForge 26.3.0.95 或更新的版本**、**Java 25**。客户端和服务端都要装。

0.14.0-alpha 的存档能直接打开。从这一版起，1.x 的版本都能读之前的存档。

## 0.14.0-alpha 以来的新内容

- **钓鱼**：多功能工具装上钓鱼器就能钓。96 种鱼分 8 种水域，按星球、生物群系、昼夜、天气和水深出，每颗星球各有一套。收线要看张力。图鉴、放生、专门的鱼饵、捕鱼笼、七道海鲜菜。
- **聚落**：没有总督的外星人聚落能接管。盖总督办公室、住宅、农场、炮台、鱼塘等十种建筑，每天出产、交维护费、替总督拿一个主意；海盗来了一起守。
- **化石**：从化石土里挖出 8 个类群的骨头，在骨架展台上拼成一副立体的骨架，封装成展品卖给收藏家。
- **深空**：碎片带、废弃的太空前哨站、能一块块拆的太空残骸，反应堆芯拆走以后残骸会熔毁。牵引光束把东西吸进货舱，货能抛掉，太空里任何船都能下船。
- **局部危害**：间歇泉、火山喷发、孢子云、尘卷风。多功能工具新添引力抓取器，能抓起 16 格内的东西再扔出去。
- **技术格**：外骨骼、多功能工具、驾驶台的技术格有了相邻加成和超频格。
- **机甲舰队**：地面编队（原型机、精准无人机、攻击无人机）和太空舰队（炮艇、驱逐舰）跟着你打黑雾。能量护盾、护盾爆发、胸甲上的三种武器、干扰胶囊。
- **物流调度**：星际物流站有名字、分组、伙伴、指定配对和最小载货量；物品路线能指向还没有工厂的星球。控制面板（I）列出全星团的物流站，在哪儿都能改自己的站。
- **统计和研究**：上下游配方、各星球和星系的进出口、电力和戴森球的分项，图表能钉在屏幕上。研究队列。
- **全息信标和备忘**、黑雾透镜、矿脉的枯竭提醒、蓝图只贴设备和显示花费。
- **声音**：171 个原创音效，全部用脚本合成。一片车间的机器声混成一种环境声，飞船的声音分三层，真空和稀薄大气里声音发闷。
- **材质**：900 多张贴图按一套调色板重画，设备从正面认得出用途，运转时夜里发光。
- `/universe` 调试命令的反馈有了英文。
- 多人：堵上了两处复制物品的漏洞，两个人同时开一艘船的货舱也不能各拿一份了；别的玩家的物流站只能看，不能远程改。

完整的改动见 [CHANGELOG.md](https://github.com/sweetcornna/universe/blob/main/CHANGELOG.md)。

## 兼容

- **JEI**：每种设备配方一个分类，标出要研究的科技。
- **Jade**：指着设备显示功率、在做什么、缺什么。
- **电网接口**：别的模组的机器能接寰宇的电；流体走罐子、泵和抽取器。
- **Sodium** 要 0.9.3-beta.1 或更新（0.9.2 本身在现在的 NeoForge 26.3 上启动就崩，和本模组无关），**Iris** 1.11.7 配它能用。
- 装了 **Sound Physics Remastered** 时，真空和水下的声音交给它处理。

## 已知问题

- 剧情文字是占位稿，之后会重写。
