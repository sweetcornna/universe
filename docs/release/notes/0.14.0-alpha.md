第一次公开测试版。需要 **Minecraft 26.3**、**NeoForge 26.3.0.95 或更新的版本**、**Java 25**。客户端和服务端都要装。

主线从坠毁的探测器一直做到戴森球和最后的「任务完成」，每一段都在游戏里验过，但还没有人从头到尾完整玩过一遍。剧情文字还是占位稿，正式版之前不保证存档兼容。

## 玩法

- **宇宙**：每个世界一个星团，建世界时定 32–256 个恒星系（默认 64），几百颗能降落的星球，全部由世界种子算出来。主世界是母星，夜空里的月亮就是第一个目的地。
- **星球**：8 类星球，各有地形、天空、天气、植物和动物。高温、严寒、毒性、辐射四种危害，重力各不相同。毒雾星球的海和雨是酸的。
- **生存**：外骨骼管氧气和防护，多功能工具开采、扫描、战斗，技术模块升级。动物能喂养、驯服、骑乘。
- **飞船**：用方块拼起来，起飞、太空飞行、降落、星际跃迁。武器、护盾、海盗袭击、小行星采矿，空间站里交易和接任务。探索车、潜艇。
- **工业**：传送带、分拣器、电网和矩阵研究，五种设备配方，七种矩阵和一棵科技树，研究完以后还有无限升级。行星内和星际物流，蓝图。
- **戴森球**：编辑器里排轨道和球壳，也能自己摆节点、连框架、铺壳面、上色，一层能导出成蓝图串分享。弹射器发射太阳帆，发射井发射火箭搭骨架，射线接收站把能量收回地面。建到一半的戴森球就挂在天上。
- **外星文明**：三个外星种族，各有一种 64 个词的语言。在对话和知识石上学词，送礼，攒种族和三个公会的声望。
- **黑雾**：在星球上建基地，在太空里建巢穴。挨打会升级，威胁满了来打你的工厂，还会派中继站和种子去别处扎根。五种炮塔，信号塔、干扰塔、行星护盾。
- **手册和进度**：游戏内手册 14 章，进度树「寰宇」跟着主线走。中英文都有。

## 兼容

- **JEI**：每种设备配方一个分类，标出要研究的科技。
- **Jade**：指着设备显示功率、在做什么、缺什么。
- **电网接口**：别的模组的机器能接寰宇的电；流体走罐子、泵和抽取器。
- **Sodium** 要 0.9.3-beta.1 或更新（0.9.2 本身在现在的 NeoForge 26.3 上启动就崩，和本模组无关），**Iris** 1.11.7 配它能用。

## 已知问题

- 开光影包时本模组的星球和太空用的是光影包的主世界天空，太空里是蓝天白云。要光影包那边支持。
- 剧情文字是占位稿。
- 跨恒星系的跃迁运输只有单元测试，没在游戏里跑过一趟。
- 专用服务器能加载、游戏内测试能过，但还没长时间开服跑过。
