# 玩法设计（草案 v0）

> 2026-10-16 · 随开发迭代更新
> 优先级：P0 是 1.0 必须有的，P1 是 1.0 争取有的，P2 放到 1.0 之后再说

## 1. 宇宙结构

### 1.1 层级

星团 → 恒星系 → 行星 / 卫星。所有内容都由世界种子派生，同一个种子永远得到同一个宇宙（见[技术架构](02-architecture.md) §3.1）。

| 层级 | 默认数量 | 说明 |
|---|---|---|
| 星团 | 每个世界 1 个 | 恒星系分布在三维空间中，星图可以旋转查看 |
| 恒星系 | 64（可配置） | 1 颗恒星，1–6 颗行星，行星可以带卫星 |
| 可登陆星球 | 约 200–300 | 气态巨行星不能登陆 |

### 1.2 母星系

- 主世界就是母星，主世界的太阳就是母星系的恒星。
- 主世界夜空里的月亮就是母星的卫星，也是玩家的第一个目的地。
- 母星系另有 2–4 颗行星，其中至少一颗气态巨行星（后期用来采集氢等资源）。
- 母星系的恒星固定为类太阳的 G 型星，保证前期体验稳定。

### 1.3 恒星类型

| 类型 | 光度 | 特点 |
|---|---|---|
| M 型红矮星 | 低 | 最常见；太阳能和戴森球产能低 |
| K 型、G 型 | 中 | 母星系是 G 型 |
| F 型、A 型 | 较高 | |
| B 型、O 型蓝巨星 | 很高 | 稀少；戴森球产能高 |
| 红巨星 | 高 | 体积大，周围的行星偏热 |
| 白矮星 | 低 | 可能出现稀有矿物 |
| 中子星 | — | 出产特殊磁性矿物 |
| 黑洞 | — | 最稀有；出产奇异物质类资源 |

恒星光度会影响行星温度、太阳能板发电量和戴森球产能。

### 1.4 命名与发现

- 每个恒星系、星球、物种都有程序生成的名字（中文、英文各一套音节表）。
- 第一个扫描到它的玩家可以重新命名。名字全服共享，发现日志记录发现者。

## 2. 星球

### 2.1 环境参数

| 参数 | 影响 |
|---|---|
| 类型 | 地形风格、方块配色、动植物基调 |
| 尺寸 | 世界边界：卫星 2k–5k 格，行星 8k–30k 格（可配置） |
| 重力 | 跳跃高度、下落速度、摔落伤害（用原版的重力等实体属性实现） |
| 大气 | 可呼吸 / 稀薄 / 有毒 / 无；决定是否消耗生命维持、天空颜色、会不会下雨 |
| 温度 | 由恒星光度、轨道距离、大气决定，随昼夜和海拔变化 |
| 危害 | 寒冷、高温、毒性、辐射中的 0–2 种 |
| 昼夜长度 | 由自转周期决定；部分星球潮汐锁定，分永昼面和永夜面 |
| 液体 | 水、熔岩、酸液，或者没有 |
| 天气 | 风暴会让危害成倍增加、能见度下降 |
| 资源 | 矿脉的种类和储量、特殊资源 |
| 生态 | 动植物的丰富程度和配色 |

### 2.2 星球类型（初版）

| 类型 | 景观 | 主要危害 | 代表资源 |
|---|---|---|---|
| 宜居 | 草原、森林、海洋，色彩随机 | 无或轻微 | 木材、常规矿物、有机资源 |
| 荒芜 | 陨坑、岩原，稀薄大气 | 无氧 | 铁、钛 |
| 冰冻 | 冰原、冰川、冰洞 | 寒冷 | 可燃冰类、氢 |
| 灼热 | 熔岩海、玄武岩、裂谷 | 高温 | 硫、硅、稀有晶体 |
| 毒雾 | 酸海、菌林、沼泽 | 毒性 | 原油、有机晶体 |
| 辐射 | 发光植被、结晶荒原 | 辐射 | 放射性矿物 |
| 海洋 | 群岛、浅海 | 视星球而定 | 水生资源、盐类 |
| 奇异 | 六种子类型，每颗星球一种，照现实里的极端地貌放大到整颗星球：柱状玄武岩、石林、巨晶、结核球、多边形地面、天然石拱（ADR-0030） | 不固定 | 光学晶体等稀有资源 |
| 卫星（特殊） | 尺寸小、重力低、没有大气 | 无氧 | 随所属行星而定 |
| 气态巨行星（特殊） | 不能登陆 | — | 用轨道采集器采集氢、重氢等 |

### 2.3 地表边界

星球地表是有世界边界的平面世界。"环绕"（从东边界走出去、从西边界回来）需要首尾相接的无缝噪声，列为 P2 实验。

## 3. 星球生存

### 3.1 外骨骼

- 一套四件的盔甲，提供生命维持（无氧环境下的供氧时间）、危害防护（每种危害一条能量条）和护盾。
- 胸甲上有科技模块槽，可以装喷气背包、防护强化、生命维持扩容、移速提升等。
- 生命维持消耗"氧"类资源（来自特定植物或电解），危害防护消耗电池。基地里可以建补给站自动补充。
- P0：生命维持、温度防护、喷气背包。P1：模块系统、护盾。
- 已实现（M2，[ADR-0010](adr/0010-exosuit-and-hazards.md)）：头盔加胸甲密封后供氧 10 分钟，不穿只能憋 15 秒；寒冷、高温、毒性、辐射各一条防护，整套标准强度撑 5 分钟，缺件更快；喷气背包在空中再按一次跳跃启动、按住上升，能连续推 2.5 秒，落地充电。氧气罐（玻璃瓶、铜、树叶）和防护电池（铜、红石、煤）右键补一半，数值低于两成时自动取用。飞船舱内有生命维持。左上角的面板显示所在星球的温度、重力和各项读数。

### 3.2 危害规则

- 在危害环境中，防护条持续下降，降到零之后开始掉血。
- 待在室内、洞穴里，或者靠近热源/冷源，下降会变慢；风暴时会加快。危害强度随星球而定：越冷、越热的星球消耗越快。
- 原版的饥饿、溺水机制照旧。

### 3.3 重力

每颗星球调整实体的重力相关属性：低重力跳得高、落得慢，高重力反过来。重力加速度按星球重力缩放；高重力下起跳速度适当加强，保证还能跳上一格；安全摔落高度除以重力、摔落伤害乘以重力（月球上从 20 格摔下相当于母星上 4.8 格）。

## 4. 多功能工具

| 模式 | 作用 | 优先级 |
|---|---|---|
| 采矿激光 | 用持续的光束开采方块和矿脉，会过热 | P0 |
| 扫描 | 发出脉冲，在 HUD 上标出附近的资源和兴趣点 | P0 |
| 分析目镜 | 看向植物、生物、矿物或星球，记入发现日志并获得勘探数据 | P1 |
| 战斗 | 射击 | P2 |

工具可以升级、加装模块。玩家前期在坠毁的探测器里找到一把损坏的工具，修好后开始使用。

已实现（M2）：

- 采矿激光：主手拿着按住使用键，朝 10 格内的方块发射光束。能挖镐、锹、斧能挖的方块，挖掘等级相当于铁镐（钻石级的矿挖不动，只溅火花），速度比铁镐快一半；挖下的方块照常掉落。连续开火 4 秒过热，过热后强制冷却 2 秒、热量归零才能再开火；平时松开 0.5 秒后开始散热。准星下方有热量条。
- 扫描：潜行时按使用键发出一次脉冲，把 32 格内的矿石（本模组的星球矿和原版矿）按 4 格的距离并成矿脉，HUD 上每条矿脉一个按矿种着色的标记，最近的 12 条写着矿名、块数和距离，30 秒后淡出。冷却 5 秒。
- 坠毁的探测器：新世界里第一个玩家进入时，在出生点外 60–110 格的干燥地面上砸出一个陨坑，坑里是船体板的残骸和一个信号篝火（烟柱远远就能看到），聊天栏提示方向和距离。箱子里有损坏的多功能工具、六页的探测器日志（介绍工具、外骨骼、飞船和卫星上的钛），以及一点起步物资。损坏的工具用 2 铜锭、2 红石、1 铁锭修好；多人游戏里其他玩家用钻石、红石块等从头合成。超平坦世界、四周全是水时不放。

## 5. 飞船

### 5.1 一次航行

1. 用方块搭出飞船：驾驶台、推进器、燃料舱、脉冲引擎、座椅、船体板，外形和用什么方块装饰都由玩家决定。在驾驶台上右键，连在一起的方块组装成一艘船（[ADR-0008](adr/0008-block-built-ships.md)）。
2. 给燃料舱加燃料，登船起飞；推重比不够飞不起来，要多装推进器或换轻的材料。
3. 飞过星球的建筑高度上限，进入所在恒星系的太空维度。
4. 在太空里开脉冲引擎高速飞行，接近目标星球。
5. 进入大气层，切换到星球维度，降落。
6. 星际旅行：打开星图，消耗空间翘曲器，跃迁到目标恒星系的太空。

### 5.2 系统

| 系统 | 作用 |
|---|---|
| 船体 | 任意方块，质量计入推重比；耐久和修理以后再做 |
| 推进器 | 从地表起飞、在大气中飞行，消耗燃料；装得越多推力越大 |
| 燃料舱 | 存燃料，装得越多航程越远 |
| 脉冲引擎 | 太空中的高速飞行 |
| 跃迁引擎 | 在恒星系之间跃迁，消耗空间翘曲器 |
| 货舱 | 船上的箱子随船走，停船后照常使用；飞行中按 H 打开货舱界面，把船上所有箱子并成一页看 |
| 扫描仪 | 在轨道上查看星球信息 |
| 武器 | P2 |

- 飞控是街机式的，不做真实的牛顿力学。大气中有燃料就自动悬停，没人驾驶时慢慢降落，默认第三人称视角。
- 飞船的档次由部件决定：以后加更高级的推进器、引擎、跃迁引擎，搭的船越大越重，需要的推力越多。
- 座椅让别的玩家一起乘船。P1：远程召唤飞船。

## 6. 太空

- 每个恒星系有一个太空维度：空无一物的虚空，背景是星空和恒星，行星以缩小比例的球体呈现。
- 行星在太空中的位置沿轨道缓慢变化（M2 可以先固定不动）。
- 飞进行星的"大气球"就切换到这颗行星的维度，落点由进入方向换算成地表坐标。从地表升到顶部则回到太空，出现在这颗行星附近。
- P2：小行星带采矿、空间站、星际货船。

## 7. 发现与勘探

- 扫描和分析的结果记入发现日志：恒星系、星球、物种、矿物。
- 兴趣点：坠毁的飞船或探测器（修复后得到部件）、先驱者遗迹（剧情和稀有蓝图）、资源富集区、地质异常。
- 勘探数据是探索的产出，用来解锁部分科技，比如特定星球的配方、飞船升级。探索和工业因此互相推动。
- 剧情保持轻量：一个"先驱者"文明曾试图建造戴森球，遗迹里留有线索（P2 再展开）。

## 8. 生态

- 每颗星球从植物形态库里挑一组植物（草、灌木、程序拼装的树），用星球的调色板着色。部分植物产出氧、燃料、有机物等资源。
- 生物（M7）由体型模板（四足、两足、六足、飞行、游泳、爬行）× 部件变体 × 配色 × 体型大小组合而成。行为分为温顺、易受惊、有攻击性、捕食者，掉落有机资源。

## 9. 工业

### 9.1 资源

- 矿脉节点是成片分布在星球表层的特殊方块，每个节点储量很大（数千到数万单位），用采矿机开采，采完后变回普通石头。扫描可以找到矿脉区。这样不必把星球挖空，"找好矿点"也成了探索的一部分。
- 每种能用镐挖的固体资源都有一种星球矿石（铁、铜、煤，加上钛、硅、硫、可燃冰、光学晶体、有机晶体、铀、岩盐、磁铁矿、奇异物质），按星球的资源表和丰度在星岩里成脉生成，一半贴近地表、峭壁和洞壁上就能看到。矿石的底色跟着星球的岩石染色，矿点不染色。前期手工开采，粗矿进熔炉、高炉炼成锭。母星的卫星一定有钛。
- 原版矿石在主世界照常生成；星球上保留金、红石、钻石、青金石，铁、铜、煤换成星球矿石。
- 液体靠抽水站和原油萃取站（原油井的产量随时间衰减）获取。抽水站放在酸海的源头上抽出硫酸（ADR-0030）。
- 气态巨行星用部署在轨道上的轨道采集器开采，产出直接进入星际物流网络。

### 9.3 传送带与分拣器

- 传送带分三档，速度约为每秒 6、12、30 个物品；可以上下坡，可以分流、合流。
- 分拣器在传送带、设备、箱子之间搬运物品，可以设置过滤，同样分三档速度。
- 传送带可以直接接入储物仓和物流站；生产设备要通过分拣器存取。这和戴森球计划一致，让产线一眼看得懂。
- P2：物品堆叠运输（一格放多件）。

### 9.4 电网

- 电力感应塔覆盖一片区域，范围内的设备自动接入，不用拉线；连接距离内的塔自动连成一个电网。
- 每个电网每 tick 结算一次总发电量和总耗电量。供电不足时，所有设备按满足率降速运行。
- 发电方式：风力（随星球风力和海拔变化）、火力、太阳能（随恒星光度和距离变化）、聚变、射线接收站、人造恒星。蓄电器负责削峰填谷。
- 和其他模组互通：电网接口接在电力感应塔的范围里，通过 NeoForge 的能量接口输入或输出，1 J = 1 FE，每刻最多 2250 J（ADR-0030）。

### 9.5 研究

- 矩阵研究站消耗矩阵推进科技树，科技树界面按阶段展示。
- 部分科技需要勘探数据（见 §7）。
- 研究进度全服共享，不分队伍（ADR-0030）：科技的效果按世界读，联机时大家一起推一棵科技树。

### 9.6 物流

- 行星内物流站之间由无人机自动搬运，范围是同一颗星球。每个站点给每种物品设置"供应"或"需求"。
- 星际物流站之间由运输船搬运，可以跨星球、跨恒星系，消耗燃料；跨恒星系还要消耗空间翘曲器。
- 物流在服务端的全局数据里结算，不依赖运输工具实体。无人机和运输船只是让玩家看得见的表现。

## 10. 戴森球

### 10.1 戴森云

- 在戴森球编辑器里设定轨道（半径、倾角）。
- 电磁轨道弹射器把太阳帆射入指定轨道。太阳帆组成戴森云，持续发电，但有寿命，会逐渐消散。

### 10.2 戴森球壳

- 在编辑器里设定层（半径、朝向），选择网格模板，例如不同细分等级的测地线网格；也可以不用模板，按经纬度自由摆节点、连框架、铺壳面，节点、框架、壳面能上色，一层能导出成蓝图文字串分享（ADR-0030）。
- 垂直发射井把小型运载火箭送上轨道，建造节点和框架；节点吸收轨道上的太阳帆，铺成球壳。
- 球壳建成后永久存在，发电量远高于戴森云。

### 10.3 能量接收

- 射线接收站把戴森球的能量送进地面电网。同一恒星系的所有接收站分享戴森球的总功率，每座接收站有功率上限。
- 在星球上，只有恒星在地平线以上时接收站才工作；潮汐锁定星球的永昼面可以一直工作。
- 装入引力透镜后切换为光子模式，产出临界光子，它是反物质的原料。

### 10.4 视觉

- 太阳帆是沿轨道运动的光点，框架是线条，球壳是半透明的发光面板，建造过程实时可见。
- 在该恒星系的任何星球上和太空中都能看到。在主世界抬头，就能看见太阳外面自己造的戴森球。
- 提供画质档位和按距离分级的细节，避免拖累帧率。

## 11. 与原版和其他模组的关系

- 不改动主世界的地形生成（与其他地形模组兼容），只额外添加坠毁的探测器、矿脉节点、原油涌泉。
- 下界和末地保持原样，可以作为特殊资源的来源，例如下界石英是前期的硅来源。
- 对主世界天空的改动（月亮、行星、戴森球）可以在配置中关闭，方便与光影或其他天空模组共存。
- 其他模组的管道、电缆可以通过 NeoForge 的通用接口接入本模组的设备：物品走所有带库存的设备，电力走电网接口（§9.4），流体走储液罐、抽水站和原油萃取站，一个流体物品算一桶（1000 mB）。原油、精炼油、氢、重氢按 NeoForge 的通用流体标签找对应的流体，找不到的照旧走物品接口（ADR-0030）。

## 12. 多人

- 发现日志和星球命名全服共享。
- 物流站、发电设备和科技全服共用，不分队伍（ADR-0030）：物流站本来就是一张全服的网，按队伍分开要把玩家传进几十处科技读取。
- 戴森球按恒星划分，所有玩家可以合作建造。

## 13. 数值原则

- 每个配方给出明确的耗时和整数比例；设备速度按档位倍率计算（例如 Mk.I ×0.75、Mk.II ×1、Mk.III ×1.5），玩家可以自己算出产线配比。
- 某些资源只出现在特定的星球类型或恒星类型上，让探索有实际收益。
- 自动化用来消除重复劳动，手工合成只在前期需要。
- 尊重 MC 的尺度：物品堆叠上限 64、一天 20 分钟、玩家的操作量有限。从戴森球计划换算数值时要按这个尺度调整。
