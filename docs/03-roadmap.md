进度：

- [x] S1 运行时维度：通过（2026-10-16），结论和遗留问题见 [ADR-0004](adr/0004-planets-as-runtime-dimensions.md)。
- [x] S2 星球地形：通过（2026-10-16）。8 类星球、10 种标志性地貌、31 种群系，区块生成比原版主世界快 30%–50%，见 [ADR-0005](adr/0005-planet-terrain.md)。遗留：原版雕刻器、酸液、星球矿石（地表植被已在生态里补上）。
- [x] S3 天空渲染：通过（2026-10-17），开 Iris 的表现待测。星球天空里能看到恒星、其他行星和卫星（相位、自转、行星环）、每个星系自己的星空和银河；天色、雾、云、日落、水色按星球变化；每颗星球自己的天气（雨雪、雷暴、沙尘、火山灰、晶尘），见 [ADR-0006](adr/0006-planet-sky-and-weather.md)。遗留：Iris 实测、酸雨的颜色和腐蚀。
- [x] S4 飞船跨维度：通过（2026-10-17）。飞船改为玩家用方块拼装，服务端飞控；飞船从主世界飞进太空，降落到卫星，再飞回主世界原来的起飞点。选了方案 A（真实坐标）：开脉冲引擎高速飞行时服务端平均 5.4 ms/刻，太空区块不存盘。见 [ADR-0008](adr/0008-block-built-ships.md)。遗留：多人测试、船上方块不工作、太空里行星不沿轨道移动。
- [x] S5 传送带性能：核心层通过（2026-10-17）。按线路推进，1 万段、4 万物品每刻 0.018 ms（预算 2 ms），三档速度的吞吐精确到每秒 6、12、30 个，见 [ADR-0009](adr/0009-belts-and-power-core.md)。游戏内 1,000 段的验证随 M3 的传送带方块一起做。
- [x] S6 电网：核心层通过（2026-10-17）。覆盖式电网的合并、拆分经随机增删和暴力算法对照；200 台设备每刻 0.005 ms（预算 0.5 ms），见 [ADR-0009](adr/0009-belts-and-power-core.md)。游戏内验证随 M3 的感应塔和设备一起做。
- [x] 星球生态（M1 追加，2026-10-17）：按种子生成的地面植物（11 种形态）、树（11 种树形）和动物（5 种体型，外观、花纹、性情、叫声都随机），动物按生境成群刷新，有逃跑、躲避、还手、捕猎等行为，掉落肉和兽皮，见 [ADR-0007](adr/0007-planet-ecology.md)。遗留：水生动植物、繁殖驯养、分析目镜。

- [x] 收尾（2026-10-17）：技术架构 §3、§4 随各个原型更新；ADR-0004 补上收尾时的状态，没处理的遗留问题列进 M2；重新估算了后续里程碑（见上表）。

退出标准：新建生存世界，不作弊，能造出飞船、飞到卫星采集钛并返回。

- [x] 退出标准验证（2026-10-17）：新建普通地形的生存世界，开局提示坠毁点方位；用原版材料能做的部件（命令发放，相当于合成好的）拼一艘 19 个方块的船，加煤、在驾驶台上组装，起飞进入太空，按仪表盘的方位飞到卫星，降落、停船；外骨骼供氧和防寒正常，扫描仪标出地下的钛矿，激光挖到粗钛；重新组装飞船，起飞返回母星降落。没有用命令改变游戏进程（传送只用来回到竖井口）。
- 验证中发现并修好：
  - 26.x 的 `dirt` 标签不含草方块了，停在草地上的船会把整片地面算进船身，提示"太大"而组装不了。改用 `substrate_overworld`。
  - 一直按着空格穿过大气层，进入太空后会继续上升，几百格后从卫星上方飞过去。现在刚穿过大气层时升降键要松开一次才生效；仪表盘给每个天体标出高度差（▲▼），太空里的按键说明加上升降键，面板跟着最长的一行变宽。
  - 坠毁点放在了树干顶上、山坡上：改为从地面算高度，挑起伏最小的地方；冲击波吹倒周围的树、烧焦地面，坑外犁出一道沟，摆几根倒下的树干，两个信号篝火。

- [x] Mk.I 传送带和分拣器、储物仓（2026-10-17）：传送带按线路模拟，坡道、自动弯道、侧面汇入，客户端重放、服务端快照校正；手放手拿、推动生物、收掉落物；分拣器带过滤、转臂动画，能在传送带、容器和设备之间搬；储物仓能当线路尽头
- [x] 配方和研究、电弧熔炉、制造台 Mk.I（2026-10-17）：三种设备配方类型（冶炼、制造、精炼），要研究解锁的有序合成；全服共享的研究进度（上交物品、研究站攒点）和调试命令；配方设备的界面能选配方、画原料虚影，按电力推进
- [x] 矩阵研究站、科技树界面（2026-10-17）：研究站按全服当前的科技消耗矩阵攒点，几台叠加；科技树按前置分列，能拖动，详情里上交物品、开始或停止研究；默认 J 键打开
- [x] 蓝、红矩阵的完整产线（含原油和精炼）（2026-10-17）：铁、铜、煤露头上的采矿机和原油涌泉上的萃取站供料，电弧熔炉炼磁铁、铁、铜和石墨，制造台做线圈、电路板和两种矩阵，精炼厂出氢，分拣器在设备之间搬运，传送带送进研究站；单元测试检查整棵科技树在生存里走得通
- JEI 配方显示

退出标准：生存模式下能自动化生产蓝、红矩阵。

- [x] 退出标准验证（2026-10-17）：在测试世界里用数据包函数摆出整条产线，相当于玩家照着科技树造好的设备；铁、铜、煤露头和原油涌泉也用命令放。然后切到生存模式运行，没再动手。
  - 蓝矩阵：采矿机供铁、铜，电弧熔炉炼出磁铁、铁锭、铜锭，制造台做出线圈、电路板和蓝矩阵。
  - 红矩阵：萃取站抽原油进精炼厂，分拣器按过滤把氢送进制造台、把精炼油送进储物仓；煤炼成的石墨和氢做成红矩阵。
  - 两种矩阵经传送带进研究站，"能量存储"的 30 点在 150 秒内自己研究完（满速是 5 秒一点）。4 座火力发电厂供电。
  - 生存里从零开始能不能走到这一步，由 `SurvivalProgressionTest` 检查：13 个科技都能完成，所有物品都拿得到。
- 验证中发现：一台采矿机接两个分拣器分给两台熔炉时，先轮到的那个分拣器一直拿得到，另一台熔炉要等前一条线堵住才有料。这和异星工厂、戴森球计划的行为一致，不算缺陷，写进了 ADR-0011；测试产线把铁矿加到 60 个节点，让产量大于磁铁那条线的消耗。

## M4 星系探索

- [x] 程序化植物、发现日志、命名、勘探数据（2026-10-17）：进入恒星系、降落星球自动记录；手持多功能工具按 V 开分析目镜，按住右键 1.2 秒分析动物、植物、树、矿石和天上的天体；第一个发现者拿勘探数据（科技"星际测绘"要上交 12 个才能研究跃迁引擎），能在发现日志（K 键）里改名，全服同步；星图上没去过的恒星系不显示行星
- 兴趣点：坠毁飞船（修好得到部件）、掉落舱（背包扩容）、废弃据点（物资和日志）、先驱者遗迹（勘探数据和线索）、埋藏的科技（扫描找到、挖出模块）、信号增强器（用导航数据定位兴趣点）
- 技术模块：外骨骼、多功能工具的技术槽，C/B/A/S 品级的升级模块，货舱扩容，个人护盾（设计见 [ADR-0014](adr/0014-exploration-rewards.md)，飞船模块挪到 M7）。2026-10-18 做完了：13 种模块，各有随机数值，第一次进背包时校准；技术配置界面（U 键），外骨骼 4–12 个技术槽、货舱 9–54 格；同一种模块最多叠三个；生命维持、四种危害防护、喷气背包、动力伺服、个人护盾、采矿激光、散热、扫描器、分析目镜都吃加成；背包满了自动收进货舱，死亡时货舱跟背包一起掉落。还没做：B 级以上模块的来源、掉落舱扩容（随兴趣点一起做），C 级配方加守卫机残骸（随守卫机一起做）
- 多功能工具的武器模式
- 守卫机：每颗星球的守卫强度，过度开采、捕杀动物提高警戒，几档守卫机，脱离视线后降级，击败掉落

退出标准：能跃迁到别的恒星系，登陆至少 4 种不同类型的星球；在星球上探索兴趣点拿到模块并装上；过度开采会招来守卫机。
