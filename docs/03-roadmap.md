- [x] 退出标准验证（2026-10-17）：新建普通地形的生存世界，开局提示坠毁点方位；用原版材料能做的部件（命令发放，相当于合成好的）拼一艘 19 个方块的船，加煤、在驾驶台上组装，起飞进入太空，按仪表盘的方位飞到卫星，降落、停船；外骨骼供氧和防寒正常，扫描仪标出地下的钛矿，激光挖到粗钛；重新组装飞船，起飞返回母星降落。没有用命令改变游戏进程（传送只用来回到竖井口）。

  - 坠毁点放在了树干顶上、山坡上：改为从地面算高度，挑起伏最小的地方；冲击波吹倒周围的树、烧焦地面，坑外犁出一道沟，摆几根倒下的树干，两个信号篝火。

- JEI 配方显示

- [x] 退出标准验证（2026-10-17）：在测试世界里用数据包函数摆出整条产线，相当于玩家照着科技树造好的设备；铁、铜、煤露头和原油涌泉也用命令放。然后切到生存模式运行，没再动手。

  - 红矩阵：萃取站抽原油进精炼厂，分拣器按过滤把氢送进制造台、把精炼油送进储物仓；煤炼成的石墨和氢做成红矩阵。

## M9 Alpha

设计见 [ADR-0019](adr/0019-alpha.md)，量出来的数字和做法上的改动见它的"结果"。

- [x] 性能优化（2026-10-20）：`/universe perf` 按子系统计时，`/universe bench` 搭参照基地。按预算的规模（5,000 段传送带、500 台设备，另加三颗星球上的工厂）量过，本模组每刻 1.16 ms（预算 10 ms）；分拣器和传送带的查找改成二分，前面的容器塞满时分拣器隔 4 刻再试。戴森球天空的顶点每刻算一次，不再每帧重算，折算到 60 fps 常见场景约多 2.5%；客户端设置里加了戴森球画质（完整、简化、不显示）。第一次去星球约 2 秒
- [x] JEI、Jade（2026-10-20）：JEI 每种设备配方一个分类，写着要研究的科技，设备界面的进度箭头点了打开，水、原油、重氢、临界光子有说明页；Jade 显示设备功率、在做什么、缺什么，采矿机的产量和储量，射线接收站的效率，物流站每格的物品。中英文都在游戏里看过
- [x] Sodium、Iris（2026-10-20）：Sodium 0.9.3-beta.1 和 Iris 1.11.7（不装光影包）下，设备、传送带上的物品、飞船、星球地形和天空、HUD、戴森球都画得对，日志里没有本模组的警告。Sodium 0.9.2 在现在的 NeoForge 上启动就崩，和本模组无关。光影包还没测
- [x] 专用服务器和 GameTest（2026-10-20）：`runGameTestServer` 不走 EULA，4 个游戏内测试（制造台有电出货、没电停着，传送带送进储物仓，研究站攒点数）全过，服务端不加载客户端的类
- [x] 多人测试（2026-10-20）：两个无头客户端局域网联机，看了设备和传送带、设备界面、科技树、新建星球维度、主机开船和开炮、戴森球、交易和各自的信用点。修了后进服补剧情进度时往聊天栏里报"完成了挑战"的问题
- [x] 发布准备（2026-10-20）：版本号 0.7.0-alpha、模组图标、`CHANGELOG.md`、发布页文字（中英文）和截图（`docs/release/`）、README
- [ ] 在 Modrinth 和 CurseForge 发布 Alpha：用作者的账号上传；发布前在 `neoforge.mods.toml` 和发布页填上仓库地址
